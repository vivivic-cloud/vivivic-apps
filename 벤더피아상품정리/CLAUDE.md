# 벤더피아상품정리 — 이 집에서 지킬 것

사장님이 폰으로 쓰시는 화면이다. **벤더피아**(vendorpia.com)에서 받은 **상품목록 엑셀**을
골라 파이어스토어에 올리신다. 올라간 자료를 바탕으로 앞으로 가공 화면을 붙인다.

- 파일 — `벤더피아상품정리/index.html` 하나. (v0.1.0, 2026-10-03)
- 주소 — <https://vivivic-cloud.github.io/vivivic-apps/벤더피아상품정리/>
  (`index.html` 이라 폴더 주소만으로 열린다. 이 집의 다른 프로그램은 `원장관리.html` 처럼
  폴더와 같은 이름을 쓰는데, 여기는 짧은 주소를 골랐다. **이름을 바꾸면 주소가 바뀐다.**)
- 폴더 이름 `벤더피아상품정리` 는 **우리가 골랐다. 사장님이 정하신 것이 아니다.**
  사장님이 바꾸라시면 바꾼다.

## 화면 — 네 단계뿐이다

```
step-pick  엑셀 고르기
step-read  읽은 것 보이기 — 몇 줄 · 몇 칸 · 칸 이름 딱지 · 겹침 미리 알림
step-up    올리는 중 — 막대 · 「2,000 / 4,565」 · 묶음 3/12 · 50%
step-done  다 올렸습니다 — 올린 줄 · 건너뜀 · 묶음 · 걸린 시간
```

한 번에 **한 단계만** 보인다. `show()` 가 넷을 다 숨기고 하나만 켠다.

- **`.hidden { display:none !important }` 를 `<style>` 에 직접 박아 두었다(62줄). 지우지 마라.**
  테일윈드가 늦게 뜨거나 못 뜨면 테일윈드의 `.hidden` 이 안 먹어서 **네 단계가 한꺼번에
  보인다.** 실제로 그렇게 나온 것을 보고 넣었다(`83af3f8`).
- **폰 375px 이 기준.** 누르는 자리는 **44px 이상** — `.btn` 이 `min-height:48px` 다.
- **구구절절한 설명을 화면에 만들지 않는다.** 알려야 할 것은 한두 낱말 딱지로.
- **시키지 않은 것을 화면에 만들지 않는다.** 이 집에서 제일 큰 잘못이다.

## 무엇보다 먼저 — 문서 이름은 `매출처명__상품코드` 다

**이것이 이 파일에서 제일 중요한 대목이다.**

`상품코드` **하나만으로 문서 이름을 지으면 사장님 자료가 조용히 사라진다.**
같은 상품이 **매출처마다 한 줄씩** 들어 있어서다. 관리자가 전한 셈 —

| | |
|---|---|
| 엑셀 줄 | **4,565** |
| `상품코드` 가지 수 | **3,435** |
| 덮어쓰기로 사라지는 줄 | **1,130** |

`매출처명` 을 앞에 붙이면 **4,565가지, 겹침 0** 이 된다. 가장 긴 것이 26자다.
(이 셈은 **관리자가 전한 것이고 우리가 재 본 것이 아니다** — 이 판에 그 엑셀이 없다.
화면이 올리기 전에 겹침을 스스로 세어 보여 준다. 그 숫자를 믿어라.)

```js
const KEY_COLS = ['매출처명','상품코드'];   // 이 둘을 붙여 문서 이름을 만든다
```

> ⚠ **뒤에 오는 누가 「코드만 쓰면 간단한데」 하고 고치면 1,130줄이 날아간다.**
> 열쇠 칸을 줄이지 마라. 늘리는 것도 관리자와 맞춘 뒤에 한다 —
> 이름이 바뀌면 **지난번에 올린 문서가 그대로 남고 새 이름으로 또 쌓인다.**

문서 이름 규칙 (`docId()`, 258줄):

- 열쇠 둘 중 **하나라도 비면 그 줄은 건너뛴다.** 올리기 전에 몇 건인지 알려 준다.
- `/` 는 파이어스토어 문서 이름에 **못 쓴다.** 전각 `／` 로 바꿔 둔다.
- 파이어스토어가 더 막는 것 — 이름이 `.` 하나나 `..` 이면 안 되고, `__…__` 꼴
  (앞뒤가 다 밑줄 둘)이면 안 되고, 1500바이트를 넘으면 안 된다. 지금 꼴은 다 안전하다.
  **열쇠 칸을 바꿀 때 이 넷을 다시 재라.**

## 파이어스토어 — `vp_상품목록` 말고는 한 글자도 쓰지 않는다

```js
const COLLECTION = ['artifacts','vivivic-4b7ef','public','data','vp_상품목록'];
```

> ⚠ **`vp_` 로 시작하지 않는 자리에는 쓰지 마라. 읽지도 마라.**
> 같은 자리에 집 안 다른 프로그램의 **진짜 업무 기록**이 산다 —
> `product_master`·`product_overrides`·`excel_metadata` (원장관리),
> `confirmed_orders`·`cutting_plans`·`partStarted`·`partCompletions` (에이엠티),
> `wt_dev`·`wt_asked` (작업대), `amt_boxes`·`johon_boxes`·`boring_*`·`defect_reports` …
> **이름이 비슷하다고 `product_master` 에 쓰면 사장님 원장이 망가진다.**

문서 한 벌은 이렇게 생겼다 (289줄):

```js
{ fields: {칸이름: 값, …},      // 엑셀 한 줄 통째로
  source: '벤더피아 상품목록',
  fileName: '고른 파일 이름',
  updatedAt: serverTimestamp() }
```

- **한 줄을 한 문서로 둔다.** 파이어스토어는 문서 하나에 1MB 가 끝이다.
  4,565줄을 한 문서 안 배열에 넣으면 머지않아 쓰기가 거부된다.
- **올린 기록을 따로 두는 칸(`vp_upload_log` 따위)은 두지 않는다.** 지금은 안 만든다.
  문서마다 `fileName`·`updatedAt` 으로 남는 것으로 충분하다. 2단계에서 필요하면 그때 정한다.
- `setDoc` 이 아니라 `batch.set` 이고 **`merge` 를 안 쓴다** — 한 줄을 통째로 갈아 끼운다.
  같은 파일을 두 번 올려도 **중복이 안 생기고 그대로 덮인다.** 이것이 바라는 바다.

## 한 묶음 400 (파이어스토어 한계는 500)

```js
const BATCH_SIZE = 400;
```

`writeBatch` 는 **한 묶음에 500번 쓰기가 끝**이다. 4,565건을 한 묶음에 넣으면
**통째로 실패한다.** 400씩 끊어 열두 묶음으로 보낸다. **500으로 올리지 마라** — 넉넉히 둔 것이다.

**묶음 하나가 끝날 때마다 화면 숫자를 갱신한다(300~304줄).** 4천 건은 시간이 걸린다 —
아무 표시가 없으면 **사장님은 먹통인 줄 아신다.** 이 갱신을 묶음 밖으로 빼지 마라.

올리다 끊기면 **몇 건까지 올렸는지 숫자와 함께** 알린다(315줄). 지금은 그러고 나서
`step-pick` 으로 돌아가므로 **읽은 줄이 사라져 파일을 다시 골라야 한다.** 그대로 두었다.

## 값은 전부 글자로 둔다

```js
o[h] = (v === undefined || v === null) ? '' : String(v).trim();
```

**숫자로 바꾸지 마라.**

- 날짜에 연도가 없는 것이 있다 — `09-22`. 숫자로 보면 뜻이 망가진다.
- 코드에 **앞자리 0** 이 있는 것이 있다 — `0012` 가 `12` 가 된다.
- 엑셀이 날짜로 읽어 둔 칸은 `XLSX` 가 숫자를 주는데, 그것도 글자로 받아 그대로 둔다.

빈 칸은 `''` 다. `undefined` 를 파이어스토어에 보내면 쓰기가 거부된다.
**통째로 빈 줄은 안 올린다**(217줄) — 엑셀 끝의 빈 줄 때문이다.

## 머리줄을 코드에 박지 않는다

**칸 이름을 미리 적어 두지 않는다.** 파일 머리줄을 읽어 **그대로** 쓴다(198줄).
벤더피아가 칸을 하나 늘려도 안 깨지고, 늘어난 칸도 같이 올라간다.

코드가 아는 칸 이름은 둘뿐이다:

- `KEY_COLS` — `매출처명`·`상품코드`. **없으면 「상품목록 엑셀이 아닙니다」 로 돌려보낸다.**
- `EMPTY_COLS` — `조립설치비`·`유리비`·`제품비`·`판매상태`. 통째로 비어 있는 칸이다.
  **올리기는 다 올리고** 딱지만 흐리게(취소선) 보인다. 지우지 않는다.

## ⚠ 이 판에서 못 재는 것

내가 직접 재 본 것이다 (2026-10-03, 프록시가 403 으로 거절):

| 길 | 어떤가 |
|---|---|
| `cdn.sheetjs.com` | **막혔다** (403 CONNECT) |
| `cdn.tailwindcss.com` | **막혔다** (403 CONNECT) |
| `www.gstatic.com` | **막혔다** (403 CONNECT) — 파이어베이스 SDK 가 여기서 온다 |
| `firestore.googleapis.com` | 닿는다. 자격 없는 읽기는 파이어스토어가 403 으로 막는다 |
| `fonts.googleapis.com` | 닿는다 |
| `vendorpia.com` | **열려 있다** (HTTP/2 200). 들어갈 자격은 없다 |

그래서 — **브라우저에서 이 파일을 그냥 열면 SheetJS·테일윈드·파이어베이스가 다 안 뜬다.**

- **산 파이어스토어에 정말 써지는지는 이 판에서 못 잰다.** SDK 가 막힌 길에서 온다.
  `window.fb` 를 허수아비로 꽂아 **「400씩 몇 묶음이 갔나 · 문서 이름이 무엇인가 ·
  진행률이 묶음마다 갱신되나」** 까지만 잰다.
- **못 잰 것을 「됐습니다」 로 적지 마라.** 「허수아비로 묶음 나누기까지 쟀고,
  산 파이어스토어 쓰기는 못 쟀습니다」 라고 그대로 적는다.

## 재는 길

이 집에 이미 터가 있다 — **`에이엠티/tests/도구/터.mjs` 를 그대로 쓴다.** 거기 있는 것:

- **`서버()`** — 저장소를 `http://127.0.0.1:8899` 에 내준다. 이미 떠 있으면 그것을 쓴다.
  **`file://` 로 열지 마라** — 모듈과 `../shared/viggle.js` 가 안 먹는다.
- **`브라우저열기()`** — `chromium.launch()` 를 먼저 해 보고, 죽으면 판에 깔린 크로미움으로
  떨어진다. **`chromium.launch()` 를 그냥 부르면 죽는다.** 이 판에 깔린 것은
  `/opt/pw-browsers/chromium-1194/chrome-linux/chrome` 다(내가 자리를 확인했다).
  **번호를 코드에 박지 마라** — `크로미움찾기()` 가 훑어 찾는다. 판이 바뀌면 번호도 바뀐다.
- **`자재()`** — 막힌 CDN 을 대신할 것을 npm 으로 받아 시험 창에만 끼워 준다
  (`tests/.자재/`, 저장소에 안 들어간다). **여기에 `xlsx` 와 테일윈드가 이미 들어 있다.**
  → **엑셀 읽는 길은 허수아비가 필요 없다. 진짜 SheetJS 로 잴 수 있다.**
  (`자재()` 를 이 판에서 아직 돌려 보지 않았다 — 처음 돌리면 npm 으로 40MB 를 받는다.)
  **파이어베이스는 이 칸에 없다.** 그것만 허수아비다.
- 누르는 것은 **진짜 손가락**(CDP 터치)으로 잰다. `.click()` 은 확인으로 치지 않는다.
- 새 시험은 **고침이 없으면 빨개지는지 먼저 확인하고** 붙인다.

업무 자료와 상품목록 엑셀은 **저장소에 넣지 않는다.** 뿌리 `.gitignore` 가 `*.xlsx` 를 막는다.

## 이 폴더의 `.md` 는 `git add -f` 로 넣는다

뿌리 `.gitignore` 3줄이 **`*.md` 를 막는다.** 그냥 `git add` 하면 이 파일이 **조용히
커밋에 안 들어간다.** 집안 `에이엠티/CLAUDE.md`·`보링변환/CLAUDE.md` 도 그래서 강제로 넣었다.

```
git add -f 벤더피아상품정리/CLAUDE.md
```

**뿌리 `.gitignore` 를 고치지 마라.** 사장님 상시 말씀 —
**「코드수정시 요청내용외 절대 수정금지」.**

## 아직 손대지 않은 것 (고치지 말고 알아만 둬라)

- **86줄 `<div id="已">`** — 한자 이름인 빈 칸이다. 아무 데서도 안 쓴다.
  시키시면 그때 치운다. **지금 건드리지 마라.**
- **전체 안전망이 없다.** `원장관리` 에는 `unhandledrejection` 으로 어떤 실패든 `alert` 로
  띄우는 안전망이 있다(324줄). 여기는 `readBook`·올리기에 각각 `try/catch` 가 있어
  `fail()` 로 빨간 띠를 보이지만, **그 밖에서 조용히 실패하면 화면이 아무 말을 안 한다.**
- 읽은 줄은 창 안(`rows`)에만 있다. 새로 고치면 사라진다. 아무 데도 안 남긴다.

## 보고

- **되는 척하지 않는다.** 못 본 것은 못 봤다고, **잰 값만** 적는다.
- **시킨 것만 고치고, 그 밖에 본 것은 고치지 말고 말한다.**
- **사장님께 직접 여쭙지 않는다.** 막히면 상태 줄 `needs_action` 머리에
  **「관리자에게:」** 를 붙인다 — 관리자가 매시간 그것을 읽는다.
- 올렸다고 적기 전에 **`git show --stat` 으로 들어간 것을 보고** 적는다.
  (이 폴더의 `.md` 는 `-f` 없이는 안 들어간다 — 위를 보라.)
