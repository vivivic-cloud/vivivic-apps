# 납품내역 — 이 집에서 지킬 것

사장님은 **폰으로 쓰시는 가구 제조업자**다. 개발자가 아니시다.

## ⚠ 먼저 읽어라
**`viggle` 저장소의 `tools/관리자/사장님말씀.md`** — 모든 집에 걸리는 규칙이다.
없으면 바이글에게 달라고 해라. 그 가운데 **이것만은 외워라** —

- 「**코드수정시 요청내용외 절대 수정금지**」 → 시킨 것만. 그 밖은 한 줄도.
- 「**시키지 않은걸 하면 이런 허비되는 시간이 많아지죠**」 → 안 시킨 보안·막음을 만들지 마라.
- 「**말많이 하지마 … 두줄만 이야기해**」 → 사장님께는 두 줄. 어려운 말 금지.
- 「**그냥 알아서 하라고해**」 → 막히면 **정하고 가라.** 사장님 답을 기다리며 서 있지 마라.
- 막히면 **사장님이 아니라 바이글에게** 말한다.
- 채팅 **마지막 줄** — 되면 `완료됨` 세 글자. 안 되면 **안된이유 3줄 + 사장님이 하실 일 3줄.**

## ⚠ 보안 — 어기면 안 된다
- 사람 칸(수취인·전화·주소)은 **빼거나 가려서** 담는다. 원본 xlsx·PDF 는 **창고에 안 올린다.**
- **진짜 업무 자료(`원장.json`·`confirmed_orders.json`·`*.xlsx`·`*.pdf`)는 커밋하지 않는다.**
  비밀 낱말·열쇠를 저장소에 박지 않는다. ⚠ `vivivic-apps` 는 **공개** 저장소다.
- 업무 기록은 **칸을 늘리기만 하고 뜻을 바꾸지 않는다. 시키지 않은 쓰기는 하지 않는다.**
- 금액(단가·원가·FOB)은 「금액 속성은 승인된 아이디만 볼 수 있습니다.」 뒤에 가린다.
  **승인된 아이디는 아직 하나도 없다.**

## ⚠ 표 디자인 — 서류관리 제품관리 표와 늘 같게 (사장님 10-22)
사장님 말씀(글자 그대로):

**앞으로 이 집에서 표를 새로 만들거나 고치는 작업자는 누구든 이 칸을 따른다.** 표 꼴을 새로 짓지 마라.

- **클래스와 값** (우리 쪽은 같은 이름 `dpr-*` 을 쓴다 — 찾기 쉽게):
  | 클래스 | 값 |

  | `.dpr-t th` | `13px / 800 / --vg-ink`, 왼쪽, 아래 붙임, `padding:10px 12px`, **`border-bottom:2px solid --vg-ink`**, 바탕 `--vg-bg` |
  | `.dpr-t td` | `14px / --vg-body`, `padding:13px 12px`, **`border-bottom:1px solid #D6D6D3`**, 위 붙임, 줄바꿈 안 함 |
  | `.num` | 숫자 칸 — **가운데**. 머리 `th.num` 은 `min-width:84px` |
  | `.dpr-k` | 첫 칸 — `position:sticky; left:0; z-index:1;` 바탕 `--vg-bg`, `700 / --vg-ink`. 폰에서 옆으로 밀어도 붙어 선다 |

  (검은 것은 바이글 박스 꼴의 `.abox.dark` 같은 **박스 하나**의 꾸밈뿐이다 — 화면 바탕이 아니다.)

- 지금 이 꼴을 쓰는 곳: `재단.html`(자기 `<style>`), `보링·엣지·납품·실제청구명세서.html`(같은 `<style>` 넷, 몸통 `폴더쪽.js`). 표 꼴을 고치면 **이 여섯 자리를 다 같이** 고친다.

### 폴더 페이지 넷 — `보링.html` · `엣지.html` · `납품.html` · `실제청구명세서.html` (v6.0.0, 10-22, 커밋 7bd2ff9)
**바뀐 것** — 사장님 10-22 「필터링 화면을 없애고 폴더별 페이지로」. 알약 거르기 없이, 드라이브 폴더의 **파일 목록**을 보이고 파일을 누르면 그 파일에서 나온 줄만 표로 보인다. ⚠ **v6.2.0 부터 파일 목록은 걷고 월 버튼이다** — 아래 「월 버튼 v6.2.0」. 맨 위 `← 납품내역`. v6.1.0(10-22)부터 흰 바탕 · 표는 위 「표 디자인」 꼴(예전 어두운 꼴은 걷었다).

**구조**
- 네 쪽의 몸통은 **`폴더쪽.js` 한 벌**이다. 쪽 html 은 Firebase 모듈 + 겉꼴(CSS) + `window.폴더 = { 갈, 묶음?, 파일:[{이름, 열쇠?, 없음?}] }` 만 갖는다. 고칠 때는 `폴더쪽.js` 를 고치면 넷이 같이 바뀐다.
- `폴더쪽.js` 가 하는 일: 익명 로그인 뒤 `where('갈','==',쪽갈래)` 로 **제 갈래 줄만** 읽는다(읽기만) → 2026년(`달` 이 `2026-`)만 남김 → 줄의 **`서류` 칸**으로 파일에 나눔(셈 칸·달 버튼 안 파일 이름에 씀) → ~~파일 목록~~ **월 버튼(v6.2.0, 줄의 `달` 칸)** → 누르면 그 달 표(`목칸`, 2,000줄 윗금, `#표통` 화면 높이 묶기, 20초 못 닿음 안내).

- 창고에 있는데 폴더 목록에 없는 서류는 숨기지 않고 맨 끝에 「(폴더 목록에 없는 서류)」 로 붙는다 — 10-22 에는 넷 다 0.

**함정**

### 메뉴 `납품내역.html` — 인수인계 (10-22, 메뉴 작업자)
- **바뀐 것:** v5.6.2 → **v6.0.0** (커밋 `9bc6007`). 사장님 10-22 「한페이지에서 필터링으로 보이는 화면을 없애고 각 폴더별 메뉴」.

  재단 → `재단.html` · 보링 → `보링.html` · 엣지 → `엣지.html` · 납품 → `납품.html` · 실제청구명세서 → `실제청구명세서.html` · nc → 링크 없음(「비어 있음」 박스, `<div>`).
