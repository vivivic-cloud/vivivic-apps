## 함정 — 건드리면 안 되는 자리 (원문·더 많은 함정 = 판기록-2 「함정」「알아낸 것」, 각 판 절의 ⚠)
- ⚠ **시험은 진짜 파이어베이스로 나간다.** `gstatic`·`googleapis` 가 열려 있다. 시험은 `https://www.gstatic.com/firebasejs/**` 를 **`https://www.gstatic.com` 으로 시작하는 정규식**으로 가로채 가짜 SDK 를 주고 그 밖 바깥 요청은 모두 막는다(`**/gstatic.com/**` 글롭은 `www.` 때문에 안 걸린다). 10-30 에 진짜 문서가 한 건 쓰였다가 지웠다.
- 저장소에서 온 값은 **전부 `textContent`/DOM 으로** 그린다. `innerHTML` 금지.
- 기록 제목 함수는 `recTitle` — 같은 이름을 두 번 쓰면 덮어써 화면에 코드 조각이 나온다.
- `append`·`replaceChildren` 에 없을 수 있는 값은 걸러서('' ) 준다 — null 은 「null」 글자. 배열은 `.apply` 로 펼치거나 `h('div',{},배열)` 로 감싼다. 폼·링크의 `h()` 는 자식 배열을 **한 겹만** 편다.
- 정규식에 lookbehind `(?<!…)` 금지 — 옛 아이폰 사파리에서 앱 전체가 안 뜬다.
- 엑셀 시트 XML 태그 순서 · 「목록」 시트는 두 번째(시트 순서 바꾸지 말 것) · 외주계약 머리 「사업단위」와 행 「단위」가 같은 키 `unit`(칸 객체로 가른다).
- `MAT_REFS` 의 `lab` 은 옛 글자 그대로(문서 키로 저장됨, v99). 품목 머리 첫 칸이 품명(`itemPicker` 가 의존, v33).
- `cur==='check'` 일 때 `Object.keys(BYKEY)` 로 단계를 돌지 말고 `STEPS` 를 쓴다(v53). `page` 단계도 `ROUTES` 항목이 없으면 `routeOf` 로 앱 전체가 안 뜬다(v81).
- `ylwNoOf` 가 새 꼴 생산 문서의 `workNo`·`orderNo`·`planNo` 를 「영림원 번호 있음」으로 보지 않게(v171).
- 공용 부품 `shared/발주상품고르기*` 는 조혼가구와 같이 쓴다 — 함부로 고치지 않는다.
- 이 폼은 밝은 테마만(`color-scheme:light`).
- 다른 작업자와 같은 파일을 고치는 일이 잦다 — 판 번호가 겹치면 합치고 한 판 올린다. 로컬 시험 서버 포트 8765 는 다른 방이 쓴 적 있다.

## 알아낸 것 (한 줄씩 — 자세히는 판기록-2 「알아낸 것」)
- 맥 기본 python3 은 아주 긴 한 줄 .py 를 「Non-UTF-8」로 거절 → `exec(open(...,encoding='utf-8').read())`. Mac 에 `timeout` 없음, `cat > 파일` 같은 입력 대기 명령 금지.
- 시험 도구: 스크래치에 `npm i playwright-core@1.56.1`, Chromium = `~/Library/Caches/ms-playwright/chromium-1194/chrome-mac/Chromium.app/Contents/MacOS/Chromium`. `goto(주소#단계)` 는 해시만 바뀜 → `reload`. 규칙 시험은 파이어스토어 에뮬레이터 + `@firebase/rules-unit-testing`.
