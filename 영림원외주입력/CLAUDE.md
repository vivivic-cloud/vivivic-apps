## 지킬 것 (⚠ 모두 사장님 말씀 — 원문은 `보관/CLAUDE/머리규칙-말씀원문.md`)
- ⚠ **외부 프로그램(영림원 등) 화면에 맞추는 작업은 반드시 실제 작동 화면을 직접 열어 확인한 뒤 한다.** 표는 오른쪽 끝·아래 끝까지 밀어 모든 칸을 보고, 칸 이름은 화면 글자 그대로. 화면에서 못 본 칸·값은 넣지 않고 「확인 못 함」. 기록·추측·화면 밖 데이터로 칸을 만들지 않는다(10-31). 폼 `STEPS`·양식 열·`erp-spec.json` 을 고칠 때도 먼저 영림원 화면을 본다.

- ⚠ **메뉴·탭·단추 이름을 새로 짓지 않는다 — 영림원 이름 그대로**(입구 = 메뉴그룹, 탭·단계 = 화면 이름 글자 그대로, 여러 화면이면 이름을 잇는다). 기록에 없으면 짓지 말고 「확인 못 함」(11-07).
- ⚠ **모든 등록 메뉴의 기본(새 메뉴는 이것까지 끝나야 완료)**: ① 양식 다운로드·올리기 — **엑셀과 구글시트 둘 다, 구글시트는 무조건** ② 「영림원에서 불러오기」 ③ 대기 건 삭제(「선택 삭제 N건」·「대기·오류 모두 삭제」+줄 체크·건수 확인창, 공용 `delKit`·`delOk`·`delMany`, 목록 밖 카드·상자에도) ④ 저장한 항목 카드 「복사등록」(공용 `copyItem`·`copyGo`, 앞 문서를 고르는 메뉴는 `fn.take`/`fn.copy`) (11-06·11-08).
- ⚠ 구글시트 양식은 **누를 때 엑셀 양식과 같은 파일로 새로 만든다(v113)** — 드라이브 「영림원외주입력 양식」 폴더에만. 고정 시트를 만들거나 `GS_TEMPLATES` 를 되살리지 않는다. 구글시트 드롭다운은 목록 밖 입력 허용.
- ⚠ **모든 드롭다운은 목록 밖 글자도 받는다(v117).** 목록 밖 값은 저장을 막지 않고 글자 그대로 두며 「미등록」으로만 구별. 영림원에 없으면 입력 작업자가 저장하지 않고 오류 + agentNote(`AGENTS.md` 3-0-미등록). 새 칸도 같게.

## 함정 — 건드리면 안 되는 자리 (원문·더 많은 함정 = 판기록-2 「함정」「알아낸 것」, 각 판 절의 ⚠)
- ⚠ **시험은 진짜 파이어베이스로 나간다.** `gstatic`·`googleapis` 가 열려 있다. 시험은 `https://www.gstatic.com/firebasejs/**` 를 **`https://www.gstatic.com` 으로 시작하는 정규식**으로 가로채 가짜 SDK 를 주고 그 밖 바깥 요청은 모두 막는다(`**/gstatic.com/**` 글롭은 `www.` 때문에 안 걸린다). 10-30 에 진짜 문서가 한 건 쓰였다가 지웠다.
- 저장소에서 온 값은 **전부 `textContent`/DOM 으로** 그린다. `innerHTML` 금지.
- 기록 제목 함수는 `recTitle` — 같은 이름을 두 번 쓰면 덮어써 화면에 코드 조각이 나온다.
- `append`·`replaceChildren` 에 없을 수 있는 값은 걸러서('' ) 준다 — null 은 「null」 글자. 배열은 `.apply` 로 펼치거나 `h('div',{},배열)` 로 감싼다. 폼·링크의 `h()` 는 자식 배열을 **한 겹만** 편다.
- 정규식에 lookbehind `(?<!…)` 금지 — 옛 아이폰 사파리에서 앱 전체가 안 뜬다.
