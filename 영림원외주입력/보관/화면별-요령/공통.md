## 공통

### 화면 여는 법
- **메뉴 검색**: 위쪽 돋보기를 누른 뒤, 열린 **검색 입력칸을 한 번 더 눌러야** 글이 들어간다(10-31). 화면 이름(예: `워크센터등록`)을 치고 결과를 누른다.
- **화면 번호로 열기**(스크립트용): 페이지에서 `Home.OpenPageSeq(번호)`. 화면마다 `#{번호}_iframe` 이 생긴다(같은 출처라 안을 들여다볼 수 있다). — `시스템클라우드보기/CLAUDE.md`
- 「조회」를 스크립트로 누르려면 그 화면 AngularJS scope 의 `scope._base.ExpExecuteToolbarEvent("Query")`. (`scope.Query()` 직접 호출은 `sendXml` 오류, 단추 `.click()` 은 안 먹음.)
- 목록 읽기: 목록 시트 요소(`SS`·`SS1` 등)의 `GetAllData().Tables[0]` → `Columns`(항목코드)·`Rows`.
- 조회 요청(`/api/WebApi`)은 암호화돼 있다. **풀지 않는다.**
- ⚠ **브라우저 확인 창 자동 확인(11-10, 사장님 「이런 확인버튼 자동으로 누르게 못하냐」).** 브라우저 기본 창(alert·confirm)이 뜨면 확장 쪽에서는 탭이 멈춘 것처럼 보인다(스크린샷·스크립트 모두 시간초과, 작업지시생성 뒤 10분+ 두 번). 단추를 누르기 **직전에** `ylw.dlgOn()`(`공통.js`) → 누름 → 끝나면 `ylw.dlgOff()` 로 되돌리고 돌려받은 창 글(`window.__dlg`)을 기록한다. dlgOn 은 맨 위 창과 같은 출처 iframe 모두(11-10 에 13개)의 alert·confirm 을 바꿔 글을 쌓고 confirm 에 true 를 준다.
  - 쓰는 곳: **지금 하려는 동작**(시킨 저장·작업지시생성·외주발주 저장·허락받은 삭제)뿐. 창 글이 뜻밖(다른 자료 삭제·전표·정산)이거나 오류 글이면 멈추고 보고한다. 화면을 새로 열면 새 iframe 은 안 걸리므로 단추마다 다시 켠다.
  - ✅ 확인(11-10): 500498 「작업지시취소」 = 브라우저 기본 창 「작업지시취소 하시겠습니까?」 → dlgOn 으로 막힘 없이 글 기록·진행됨. 「작업지시생성」도 같은 꼴로 보인다(그 창 글은 못 봄). 「삭제」·「행삭제」 확인(「삭제하시겠습니까?」·「선택한 행을 삭제하시겠습니까?」)과 「시트 오류」 창은 **화면 안 창**이라 dlgOn 에 안 걸린다 → 스크린샷 보고 단추를 누른다.

## 표(그리드) 화면에 붙여넣기 — 복사·붙여넣기로 한 줄 넣기 (10-31 워크센터등록에서 확인)
- ⚡ **11-01 부터는 스크립트로 한다**: `스크립트/공통.js` 의 `ylw.paste` 가 붙여넣기 이벤트를 직접 보낸다(클립보드·키 누름 없음, 코드도움 됨). 체크 칸은 `ylw.setChk`(SetText). 화면별 파일·쓰는 법은 `스크립트/README.md`. 아래는 손으로 할 때와 그 까닭.
- 사장님 말씀(10-31): 「입력칸이 셀 형식인경우 셀형식의 파일에서 복사 붙여넣기가 가능한걸로 알고있어」 → **된다.**
- 만드는 법: 화면 표의 **왼쪽부터 끝까지 칸 순서대로** 값을 탭(\t)으로 이은 한 줄. 빈 칸도 탭 자리는 남긴다. 날짜는 `2016-01-01` 꼴.
- 클립보드에 넣는 법: 크롬 `navigator.clipboard.writeText` 는 **멈췄다**(권한 창 때문으로 보임, 도구가 45초 뒤 끊김). 대신 페이지에 임시 글 상자(textarea)를 만들어 줄을 넣고 선택 → **키보드 Cmd+C**(진짜 키 누름) → 글 상자 지움.
- 붙이는 법: 빈 행(A)의 첫 칸(워크센터)을 한 번 누르고 **Cmd+V**. 저장 전 `SS1.GetAllData()` 로 코드 칸(`…Seq`)이 채워졌는지 본다.
- 칸별 결과(워크센터등록 500226, 8줄 모두 같음):
  - 됨(글): 워크센터 · 시작일 · 종료일.
  - 됨(드롭다운, 글자로 골라짐): 워크센터구분(사외외주 → `SMWorkCenterType` 6011003) · Capa산정구분(작업시간 → 6038001).
  - 됨(코드도움, 이름으로 코드가 잡힘): 생산부서(기획 → `DeptSeq` 4) · 외주거래처(→ `CustSeq`) · 창고 6칸(→ `…WhSeq`).
  - 화면에 없는 숨은 원가센터(`CCtrSeq`)는 0 으로 남는다(넣지 않음). 저장 때 오류 문구 없음.
- ⚠ **여러 줄을 한 번에 붙이지 마라(원인 미확인).** 10-31 에 7줄을 붙였더니 첫 줄만 들어가고, **다음 줄의 첫 글이 첫 줄의 마지막 칸(비고)에 들어갔다**(T이룸 비고 「T로앤」, 저장됨).
  - 복사 방법: 임시 상자는 **textarea**(여러 줄 상자 — 한 줄짜리 input 이 아니었다), 줄 사이는 **`\n`(LF)** 하나, 줄 끝 비고는 빈 값. 그래서 「줄바꿈이 사라져 한 줄로 이어졌다」는 아니다.
  - 짐작(시험 안 함): 엑셀에서 복사하면 줄 사이가 `\r\n`(CRLF)이다. 영림원 표가 `\r\n` 만 줄 나눔으로 알아본다면 `\n` 이 비고 칸 글 속으로 들어간 것이다. → **`\r\n` 으로 다시 시험 필요**(시험은 저장하지 말고 붙여 본 뒤 「조회」로 버린다).
  - 그때까지는 한 줄씩 복사·붙이기. 줄 끝에 줄바꿈을 붙이지 않는다.
- ⚠ 붙인 뒤 저장 전에 **모든 칸을 끝 칸(비고)까지** 읽어 폼 값과 맞춘다. 코드 칸만 보고 넘어가지 않는다.
- ⚠ 손으로 칠 때와 다름: 생산부서 칸에 「기획」을 타자+Enter 했을 때는 안 잡혔다(빈 칸). 붙여넣기는 잡혔다.
