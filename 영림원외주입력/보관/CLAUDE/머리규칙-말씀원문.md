# 영림원외주입력 — 이 집에서 지킬 것

영림원 ERP 테스트서버(아이앤지퍼니처 TEST)에 생산외주 자료를 등록하기 전에,
사람이 단계별로 입력해 두는 폼이다. 나중에 에이전트가 이 폼에 쌓인 것을 읽어 ERP에 넣는다.

> 영림원 입력 작업자는 `입력작업자/AGENTS.md` 부터 읽는다(`영림원외주입력/입력작업자/AGENTS.md`).

> ⚠ **메뉴·탭·단추 이름을 새로 짓지 않는다. 영림원 이름 그대로 쓴다.** 페이지 입구는 메뉴그룹, 탭·단계는 화면 이름 글자 그대로. 한 탭이 영림원 화면 여럿이면 화면 이름을 그대로 잇는다(예: 구매요청입력·구매품의입력·구매발주입력). 기록에 영림원 이름이 없으면 짓지 말고 「확인 못 함」으로 적고 둔다. 사장님 말씀(글자 그대로): 「각 메뉴 이름을 새로 만들지말고 영림원의 이름을 그대로 해라 지금 생산관리 새생산 이란 말이 영림원에 있는말이냐?」 (2026-11-07)

> ⚠ **모든 등록 메뉴의 기본 규칙 — 새 메뉴를 만들 때 이것까지 끝나야 완료다.**
> - 모든 등록 메뉴에 **양식 다운로드·올리기(엑셀과 구글시트 둘 다, 구글시트는 무조건)** 와 **「영림원에서 불러오기」** 단추가 똑같이 있어야 한다.
> - 구글시트 드롭다운은 **목록 밖 입력 허용**이다. 시트는 드라이브 「영림원외주입력 양식」 폴더에만 저장한다. **v113 부터 구글시트 양식은 누를 때 엑셀 양식과 같은 파일로 새로 만든다 — 새 메뉴에 엑셀 양식이 있으면 구글시트도 저절로 된다. 고정 시트를 만들거나 `GS_TEMPLATES` 를 되살리지 않는다.**
> - 사장님 말씀(글자 그대로): 「모든 등록 메뉴에 이것은 동일하게 나타나야하는 기본 사항 입니다」 · 「신규 작업자들이 알아볼 수 있게 깃에 메모해 주세요. 구글시트양식도 무조건 포함되어야 합니다」 (2026-11-06)
> - **모든 등록 메뉴에 대기 건 삭제 단추**(v13 꼴 「선택 삭제 N건」·「대기·오류 모두 삭제」 + 줄 체크 칸, 건수 확인창)가 똑같이 있어야 한다. 대기 건이 목록 밖(카드·요청 상자 등)에 보이는 곳에도 둔다. 공용 코드 `delKit`·`delOk`·`delMany` 를 쓴다(맨 아래 「모든 메뉴 대기 건 삭제 단추 (v103)」). 사장님 말씀(글자 그대로): 「이런 대기건들 삭제 버튼 이 없는거 같은데 모든 메뉴 해당상황에 삭제버튼 만들어야 하는거 아닌가?」 (2026-11-08)
> - **모든 등록 메뉴의 저장한 항목 카드에 「복사등록」 단추**가 있어야 한다. 공용 코드 `copyItem`·`copyGo`(맨 아래 「복사등록 (v109)」). 새 메뉴는 입력 칸이 있으면 저절로 붙고, 앞 문서를 고르는 메뉴는 `fn.take`(필요하면 `fn.copy`)가 있어야 붙는다. 사장님 말씀(글자 그대로): 「모든 등록건 저장 완료된 목록에서 복사등록이 가능하게 해주세요. 복사등옥의 개념은 다른 품목 이지만 입력 내용의 미세한 부분을 수정후 복사등록 하는것 입니다」 (2026-11-08)

> ⚠ **폼에서 수정할 수 있는 것은 폼 수정 절차로 처리한다.** 영림원을 직접 고치거나 채팅 지시로 고치지 않는다. 폼에 수정 길이 없으면 그 길을 먼저 만든다. 사장님 말씀(글자 그대로): 「일단 폼에서 수정이 되면 폼 수정 절차를 거치고 싶습니다」

> ⚠ **작업 흐름에 필요한 확인·불러오기·등록은 입력폼 안에서 끝나게 만든다.** 사장님 말씀(글자 그대로): 「「자재 등록 먼저」 이런 상황일때 팝업으로 자재를 등록 할 수 있게 해달라는 이런 흐름에 맞는 작업을 직관적으로 할 수 있게 해달라는거야 - 그럼 자재등록이 된건지 안된건지 먼저 확인해야 할테니 영림원에서 등록된자재를 불러오기도 해야 하고 확인할것이 많잖아 그런 모든 액션을 이 입력폼에서 할 수 있게 해보자는거야」 (2026-11-07)

> ⚠ **입력 작업자가 막히면 폼 문서 `agentNote` 로 바로 보고하고, 폼만 보고도 고칠 것을 알 수 있어야 한다**(꼴 = `입력작업자/AGENTS.md` 맨 위 🚩). 사장님 말씀(글자 그대로): 「이런 상황이 오면 폼에 바로 보고해서 수정해야 될 부분이 나타나도록 깃에 메모 남기고 지금 상황 폼만 보고도 뭘 수정해야 알 정도로 해줘」

> ⚠ **영림원에 없는 표기법(괄호 붙임 등)을 화면 값에 쓰지 않는다. 폼이 목록 조건이나 규칙을 임의로 정하지 않는다.** 드롭다운·칸 값은 영림원 글자 그대로만 보인다(종류·상태·이름+코드 잇기 같은 붙임 글자 금지). 목록 밖 값·오류는 값 밖의 오류 글·칸 테두리로만 보인다. 목록 조건은 영림원 화면 기준을 입력 작업자가 확인한 뒤 정한다. 사장님 말씀(글자 그대로): 「임의로 정하지 마세요. 실제거래처 이름에 없는(해외매입) 이런 표기는 다른 거래처로 오인될 수 있으니 영림원에 없는 표기법은 사용하지 마세요」 (2026-11-08, v107)
