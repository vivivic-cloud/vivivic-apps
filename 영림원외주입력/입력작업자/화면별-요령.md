## 공통

### 화면 여는 법
- **메뉴 검색**: 위쪽 돋보기를 누른 뒤, 열린 **검색 입력칸을 한 번 더 눌러야** 글이 들어간다(10-31). 화면 이름(예: `워크센터등록`)을 치고 결과를 누른다.
  - ⚠ 메뉴 검색 결과가 하나면 바로 열린다(「환경설정(관리자)」). 검색창이 열린 채 돋보기를 다시 누르면 닫힌다. 코드도움에서 못 찾으면 창이 열려 화면을 덮는다 → 닫으면 「붙여넣기를 취소하시겠습니까?」 → 확인.
- **화면 번호로 열기**(스크립트용): 페이지에서 `Home.OpenPageSeq(번호)`. 화면마다 `#{번호}_iframe` 이 생긴다(같은 출처라 안을 들여다볼 수 있다). 닫기 = `Home.CloseOpenPage(번호)`. — `시스템클라우드보기/CLAUDE.md`
- 「조회」를 스크립트로 누르려면 그 화면 AngularJS scope 의 `scope._base.ExpExecuteToolbarEvent("Query")`. (`scope.Query()` 직접 호출은 `sendXml` 오류, 단추 `.click()` 은 안 먹음.) 스크립트 조회가 새 자료를 안 보여 줄 때가 있다 → 확인은 **화면 「조회」 단추를 진짜로**.
- ⚠ 열린 탭의 표는 연 때의 값이다. 읽기 전에 조회를 다시 한다 — 스크립트는 `ylw.read.query(화면)`(조회 단추에 pointer·mouse 동작을 차례로, `click()` 은 안 먹음).
- 목록 읽기: 목록 시트 요소(`SS`·`SS1` 등)의 `GetAllData().Tables[0]` → `Columns`(항목코드)·`Rows`. 보이는 칸은 `Sheet.getColumnVisible(i)`·`getColumnWidth(i)>0` 로 가른다(`ylw.read.cols`).
- ⚠ **브라우저 확인 창 자동 확인(11-10, 사장님 「이런 확인버튼 자동으로 누르게 못하냐」).** 브라우저 기본 창(alert·confirm)이 뜨면 확장 쪽에서는 탭이 멈춘 것처럼 보인다. 단추를 누르기 **직전에** `ylw.dlgOn()`(`공통.js`) → 누름 → 끝나면 `ylw.dlgOff()` 로 되돌리고 돌려받은 창 글(`window.__dlg`)을 기록한다.
  - 쓰는 곳: **지금 하려는 동작**(시킨 저장·작업지시생성·외주발주 저장·허락받은 삭제)뿐. 창 글이 뜻밖(다른 자료 삭제·전표·정산)이거나 오류 글이면 멈추고 보고한다. 화면을 새로 열면 새 iframe 은 안 걸리므로 단추마다 다시 켠다.
  - ⚠ `ylw.reopen` 으로 화면을 새로 열면 dlgOn 이 풀린다 — 다시 켠다.
  - 브라우저 기본 창 = 「작업지시생성 하시겠습니까?」·「작업지시취소 하시겠습니까?」. **화면 안 창**(dlgOn 에 안 걸림 → 스크린샷 보고 좌표로 누름) = 「삭제하시겠습니까?」·「선택한 행을 삭제하시겠습니까?」·「변경된 내용이 반영되지 않습니다…」·시트 오류.
- ⚠ **오래 걸리는 단추(「작업지시생성」·「소요자재가져오기」 등) 뒤 탭이 멈추면 확인 창이 막은 것일 수 있다.** 누른 뒤 20초 안에 응답이 없으면 기다리지 말고 사장님께 확인 창을 봐 달라고 한다. **단추를 다시 누르지 않는다.**
- ⚠ 화면 안 「자료가 저장되었습니다.」 알림을 **닫기 전에는 재고(501179)가 안 바뀌었다** — 저장 뒤 알림을 꼭 닫고 본다.
- ⚠ 입력 화면마다 툴바 단추 자리가 다르다(예: 500173 조회·저장이 붙어 있음, 501065 x 668 저장 · 625 조회). 누르기 전 확대(zoom)·스크린샷으로 본다.
- 날짜 넘어 일할 때는 입력 화면 탭을 닫고 다시 연 뒤 일자 칸을 본다(머리 일자 = 화면을 연 날 값, 「신규」로 안 바뀜). 새 Chrome 탭은 로그인 화면이 나오므로 쓰지 않는다.
- 영림원은 화면마다 탭을 하나만 연다 — 그 탭에 남의 저장 안 된 입력이 있으면 「변경된 내용이…」 창이 뜬다. 함부로 「확인」(버림) 하지 않고 묻는다.
- 이 확장 탭은 다른 Chrome 창·다른 컴퓨터 Chrome 으로 갈 수 있다. 로그인 화면이 나오면 `list_connected_browsers` 로 어느 Chrome 인지 보고 사장님과 맞춘다.
- 도움말 읽기: `.btnHelp` 를 좌표로 진짜 클릭 → 새 탭(`cms.systemevererp.com`) → `document.body.innerText`. 자세히 → `../보관/화면별-요령/조사-운영메뉴-화면칸.md` 「읽는 요령 (11-05)」.
