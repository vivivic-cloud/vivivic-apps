# 전달 — 보드매입현황 「영림원 입력폼」(국내 보드 거래처 기준정보) (2026-11-16, v1.6.0)

입력 작업자(AI·사람 누구든)가 이 페이지의 자료를 영림원에 넣게 될 때 먼저 읽는 글.
**아직 영림원에 넣지 않는다**(사장님 결정 8). 폼이 최종본이 되면 사장님과 입력 작업자가 상의해서 시작한다. 그때 넣는 길(폼 대기 문서로 옮길지, 이 창고를 직접 읽을지)도 같이 정한다.
자세한 화면·코드 설명 = `../../발주역입력/CLAUDE.md` 「영림원 입력폼」 절.

## 2. 사장님 결정 (11-16, 그대로 따른다)
1. 범위 = 기준정보까지: **거래처(→ v1.6.0 영림원 기존 거래처 연결) → 품목대중소분류정의 → 자재등록 → 구매단가등록**. 실제 매입(발주·납품·입고정산) 역입력은 안 한다.
2. **거래처 = 영림원 기존 거래처 연결**(11-16 정정, 사장님 그대로: 「영림원 기존 거래처를 그대로 쓰기로 했습니다. 현재 영림원 입력폼 메뉴에서 거래처 상세 관련을 기존 영림원에 입력된 실제 거래처를 불러와서 연결시키는 방식으로 해야 합니다.」). 거래처를 새로 등록하지 않는다 — 처음 결정(상호·사업자등록증 읽기·거래처 관리 시트)은 v1.5.0 에 만들었다가 v1.6.0 에서 걷어냄. 구매거래처 = 이은 영림원 거래처(영림원 표기 그대로).
3. 분류(대·중·소) = 자재 줄마다 직접 넣고, 한 번 넣은 값은 드롭다운에 저절로(대→중→소). → 품목대중소분류정의(품목구분 자재) → 자재소분류로 넘긴다.
4. 자재 = 거래처마다 따로 등록(같은 보드라도 모델명이 다름). 자재명 = 납품제품명(품목) 그대로가 기본(고칠 수 있음). 자재번호 = 사장님이 직접(폼은 겹치면 빨갛게 경고만 — 저장은 됨). 기준단위 = 보드 원장 EA(매) · **양지데코 = 엣지필름, M 단가** · 현진산업 시트류(m 로 보임)는 「임시」.
5. 줄마다 확인 뒤 체크로 이번 등록에서 뺀다(`x_del`). 원본은 안 지운다. 다시 살릴 수 있다.
6. 단가이력: 영림원이 이력을 받는지는 모른다(시험은 나중에 폼에서). 그래서 **이력으로 넣을 때(여러 줄)와 마지막 단가 하나만 넣을 때 둘 다** 바로 쓸 수 있게 기록해 둔다.
7. 영림원 기존 정보 삭제 = 다른 곳에서 진행 중. 이 일에서 안 다룬다.
8. 영림원 실제 등록 = 이번에 안 만든다(등록 요청 단추 없음). 최종본 뒤 입력 작업자와 상의.

## 3. 단가이력 — 어떻게 셈했나
- 원본 월별 표(날짜 칸 없음, 「월」 만)에서 그 줄(품목+규격)의 단가를 **표 줄 차례대로** 본다. 같은 단가가 이어지면 한 묶음(사이에 안 산 달이 있어도 이음). 0원(무상) 줄은 변동으로 치지 않는다(0원만 있는 줄은 0 한 묶음).
- 묶음마다 `{단가, 첫달, 끝달, 적용시작일 = 첫달 1일}`. 날짜가 없어 **달 첫날로 둔 것 — 임시**. 현진산업·현준보드(서광)는 「별도 단가(원)」(부가세 별도).
- **이력으로 넣을 때** = 묶음들을 차례대로 구매단가등록 줄로(같은 구매거래처·품번, 적용시작일만 다름 — erp-spec purprices note 「단가 변경은 새 적용시작일 문서」). 적용종료일은 영림원이 저절로.
- **하나만 넣을 때** = 마지막 묶음(입력폼 `단가`·`적용시작일` 칸에 미리 채워진 값).
- ⚠ 한 달 안에 단가가 두 번 이상 바뀌면 묶음 둘이 **같은 적용시작일**이 된다 → 페이지에 「⚠같은 시작일」. 폼(영림원외주입력)은 같은 구매거래처·품번·적용시작일을 막는다 → 넣기 전에 사장님께 날짜를 받는다. (11-16 현재: 현진산업 YD8916-19전(친)/145-4코 · 유백A전 친(P18) · 유백A전 친(M2.7) · H백색코(P15) 등)
- 양지데코 롤 줄(규격·품목에 `*100`·`110미터` 처럼 길이)은 **단가 ÷ 길이 = M 단가**(소수 2자리). 롤 값인지는 「단가÷길이 ≥ 20원」 으로 가른다(이미 M 단가인 CS300 168·191원 줄은 안 나눔) — 임시. 나눈 줄은 `이력[].줄[].롤` 에 「롤 단가 N원 ÷ Lm」.
- 예(11-16): 엘데코 PB18T(E0) 201/양 = 19,500(1~4월, 2026-01-01) → 21,500(4~10월, 2026-04-01) · 신태광 EO MDF2.7T(R) = 4,150(1~3월) → 4,500(4월) → 4,150(6~8월, 2026-06-01) · 현진산업 백색코(M2.7(E0)) = 2,455(1~3월) → 3,000(4월) → 3,273(5~10월, 2026-05-01) · 양지데코 밀크 1.0*21*100 = 172.73(6~7월) → 163.64(8~10월) (롤 17,273·16,364원 ÷ 100m).
- 창고 `이력` 은 단가가 바뀐 품목만(11-16: 엘데코 13 · 신태광 2 · 재하기업 2 · 현진산업 18 · 현준보드 2 · 양지데코 1). 바뀌지 않은 품목은 입력폼 단가·적용시작일 한 줄이 곧 전부.

## 4-1. 영림원 거래처 목록 올리기(「불러오기」 요청이 오면) — 영림원에 쓰는 일 아님
- `_거래처불러오기` 가 「대기」면: 진행중 → 폼 `erp_vendors`(영림원 거래처조회 500373 를 불러온 것, 11-16 189곳 — `erp-spec.json` imports.vendors) 를 읽거나, 낡았으면 폼 거래처 「불러오기」(erp_imports vendors)를 먼저 돌린 뒤 →
  `_영림원거래처` 에 `{줄:[{거래처:name, 상호:sangho, 거래처상태:state, 거래처종류:kinds}], 불러온때, 출처:'erp_vendors MM-DD'}` 를 통째로 쓴다(이 네 칸만) → `_거래처불러오기` 완료 + agentNote 「N곳」.
- 페이지는 익명이라 `erp_*` 를 못 읽는다 — 그래서 이 사본이 필요하다.

## 4. 넣는 차례(그때 상의할 초안)
거래처는 넣지 않는다(이미 영림원에 있음 — `_거래처연결` 로 고른 거래처가 국내매입거래처인지만 본다, 아니면 구매거래처 코드도움에 안 잡힘) → 품목대중소분류정의(502365, 품목구분 **자재**, `_분류.줄`) → 자재등록(500251, 자재소분류 = 소분류 이름으로 코드도움, `x_del` 줄 뺌) → 구매단가등록(501868, 이력 또는 마지막 하나). 각 화면 요령 = `화면별-요령.md` · `../보관/화면별-요령/기준정보-화면.md` · `조사-원장-수입-구매.md`.

## 5. 아직 영림원에서 확인할 것(확인 못 함)
- 구매단가등록 **단가이력**: 같은 구매거래처·품번에 적용시작일이 다른 줄 여러 개를 저장할 수 있는지, 지난 날짜(2026-01-01 등)로 넣을 수 있는지, 단가 0 · 소수 2자리(M 단가 172.73) 저장.
- ~~영림원 거래처 목록이 아직 이 쪽 창고에 없다~~ → **11-16 21:34 올림(4-1, 188곳)**. 6곳 모두 영림원 같은 이름 하나로 「자동」 맞춤(엘데코·신태광·재하기업·현진산업·현준보드·양지데코, 모두 국내매입거래처·정상). 사장님이 「거래처 연결」 에서 확정(고르기)하는 일은 남음.
- 6곳(엘데코·신태광·재하기업·현진산업·현준보드(서광)·양지데코)이 영림원에 실제로 어떤 이름으로 있는지(테스트용 T엘데코·T신태광·T현진산업 말고), 국내매입거래처인지.
- 기준단위 **M**: 자재등록 기준단위 코드도움에 M 이 있는 것은 기록(엣지 M)으로 앎. 현진산업 시트·엣지·필름 줄(m 로 보임)을 M 으로 둘지 사장님 확인(「임시」 빨간 테).
- **자재소분류 이름**: 아직 없음(사장님이 입력폼에서 넣으실 것). 영림원 자재 대·중·소분류에 이미 있는 이름(T201양면 등)과 겹치는지, 같은 소분류 이름을 다른 중분류 밑에 둘 수 있는지.
- `발주역입력_영림원거래처` 컬렉션(문서 7개, 「시험거래처」 포함)은 v1.5.0 시험 자국 — **안 쓴다**. 지울지는 사장님 확인.
