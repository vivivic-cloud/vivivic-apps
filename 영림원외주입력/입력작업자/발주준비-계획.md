# 발주 준비 — 조사·계획 (11-27, 발주 준비 작업자)

목표: 기준정보 입력(품목·재공품·BOM·공정흐름·소요자재·워크센터·외주계약)이 끝나면 영림원에서 발주를 시도한다. 방식 = 입력폼 → AI 가 영림원 등록(채팅 지시 방식 아님).
이 글은 **기록 대조만**(영림원 화면 안 엶 — 11-23 사장님 「이미 확인한 내용이 있다면 영림원 실제화면 확인은 필요없습니다」). 기록 없는 것은 「확인 안 됨」.

## 1. 입력폼에 이미 있는 발주 메뉴 (11-27 판 `영림원외주입력.html`)
- 구매/수입 입구: 구매단가등록 · 구매요청입력 · 구매품의입력 · 구매발주입력 · 구매요청입력·구매품의입력·구매발주입력(묶음) · 구매납품입력 · 발주수정 · 구매입고정산처리·매입세금계산서발행(구매) — 다 있음(v126~v262).
- 생산/외주 입구: 주간생산계획입력·외주발주입력(`prods`) · 외주납품입력·자재출고입력(`proddlvs`) — 있음(v81~v171, 양식 올리기 줄 `xlCols` 있음).
- 구매발주납품 관리(`pdm`, 거래처 박스) · 구매/발주 품의(`vappr`) — 있음(v230·v266).
- ⇒ 「비어 있음」은 **메뉴가 없는 것이 아니라 자료가 비어 있는 것**(11-16 영림원 발주 자료 모두 지움, p11 202611190003 만 남음).

- 구매: 구매단가 등록 87줄(영림원 87 = 폼 완료 87, 11-26 동기화) — 단가 있는 품번·거래처 조합만 구매발주 가능. 구매요청·품의·발주·납품 길은 11-15 T 시험으로 확인됨.
- 외주: 입력 중(대기) 품목 147 · 재공품 222 · BOM 369 · 공정흐름 147 · 소요자재 147 · 워크센터 1,086 · 외주계약 5업체. **이 자료가 영림원에 다 들어가야** 폼 `prods`(needs: 소요자재·제품별워크센터·외주계약)의 품번 드롭에 제품이 나온다 — 지금은 영림원 입력 작업자 몫이라 대기.
- 빠진 것(기록상): 외주계약 5업체가 공정 규칙표(재단 AMT·경기산업·조혼가구 / 엣지 이룸·조혼·AMT·경기 / 보링 로앤·조혼·AMT / 조립 AMT·조혼·아인·진아·럭스 / NC AMT·조혼·진아)의 8업체 중 어느 5곳인지 — 폼 화면 값으로 확인 필요(이 방은 폼 자료를 아직 안 읽음). 외주계약 없는 업체·공정은 외주발주 단가 0.

## 4. 입력폼 메뉴 계획(안)
1. 이미 있는 메뉴는 새로 만들지 않는다. 비어 있는 것은 자료뿐.
2. 먼저 할 일 = 첫 시험 흐름 하나를 폼에서 끝까지: (가) 구매 1건(구매단가 있는 품번) (나) 외주 1건(공정흐름·소요자재·계약 갖춘 제품 1개) (다) 본사 자체생산 A2-alm60 — 이 흐름이 폼 메뉴로 닿는지(양식 다운로드·올리기·불러오기·확인·등록이 폼 팝업에서 끝나는지) 점검.
3. 빠진 길 후보: 본사 자체생산 작업지시·작업실적 메뉴(폼에 없음 — 영림원 이름 확인 필요) · 외주입고입력 501925·외주자재투입 501620·외주입고정산처리 501622 의 폼 메뉴 여부 · 수입(해외) 발주 가름.
4. 영림원 화면을 새로 열어 볼 항목(기록 없음, 사장님 허락 뒤): 본사 작업지시·작업실적 · 500865 본사 조립 줄.
