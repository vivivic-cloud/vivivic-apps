# 전달 — 「납품창고 = 다음 공정 업체 창고」 세팅과 실제 시험할 것 (2026-11-12)

다른 맥의 입력 작업자(AI)에게 넘기는 글. 이 글만 읽고 시험을 이어받을 수 있게 썼다.
먼저 `AGENTS.md`(특히 0 · 3-11) · `사장님-규칙.md` 끝 절 · `화면별-요령.md` 생산·외주 절을 읽는다.

## 1. 왜 바꿨나
- 영림원은 외주 공정 납품을 하면 가공품(재공품)을 **외주발주 줄의 「납품창고」**로 입고한다. 지금까지 T워크센터·발주 납품창고는 모두 **그 업체 자기 창고**였다.
  → 재단 납품 뒤 재단품이 T에이엠티 창고에 남고, 엣지(T이룸) 납품 전에 자재출고(500938 → 500940)로 옮겨야 했다. 안 옮기면 「외주자재투입 : [품번:…] 현재고가 부족하여 처리할 수 없습니다.」
- 11-12 링크 발주 44건을 넣다가 막혔다: 11-10 필름 이동 자재출고 202611100006 에 재단품 14줄이 T이룸→T이룸 으로 같이 저장돼 출고 요청 202611100016 이 「완료」로 닫혀, 재단품을 옮길 길이 사라짐.
- 사장님 말씀(그대로): 「그럼 발주에서 이걸 결정하게 해야겠네?」 · 「그럼 입력폼에서 그렇게 작동되도록 하면 되는거지?」 · 「자 그럼 모든 납품 상황에서 다음공정이 정해진 곳은 따로 출고이동 없는걸로 세팅해줘」 · (저장된 발주도) 「고쳐」.

## 2. 새 규칙
- 외주발주(501617) **줄마다 「납품창고」 = 다음 공정 업체 창고**. 재단 → 엣지 업체 · 엣지 → 보링 업체 · 마지막 공정 → 조립업체(공통부속도 `erp_prods.asmVendor`). 다음 공정이 같은 업체면 자기 창고.
- 그러면 **공정 사이 자재출고는 하지 않는다.** 엣지필름 이동(외주발주 때 T본사 → 엣지 업체)은 그대로.
- 규칙 = `사장님-규칙.md` 「다음 공정이 정해진 납품은 출고 이동 없이」 · 절차 한 줄 = `AGENTS.md` 3-11.
- 폼(`erp_prods` 줄 납품창고 값 · `erp_proddlvs` 출고 칸 비우기)은 **아직 안 고침** — 분배 방에 넘김. 폼이 고쳐지기 전에는 작업자가 생산 문서 공정 차례로 정한다.

## 3. 이미 확인한 것 (11-12, 영림원 T 시험 — 모두 지움)
- T-al-p04 1개(계획 202611240001). 재단 발주 줄 납품창고 T에이엠티 → **T이룸** 붙여넣기(코드도움 칸, WHSeq 28 → 29) → 저장됨.
- 재단 납품: 501613 줄 납품창고에 T이룸 이 저절로 → 저장. **원장 T-pb18-wt 는 T에이엠티에서 −0.11**(발주 업체 창고), **재단품 T-al-p04_1 은 T이룸 +1**.
- 엣지 납품(출고 없이): 저장됨. T이룸 재단품 −1 · 필름 −2.36 · 엣지품 _2 T이룸 +1.
- 남은 것: 두 발주의 출고 요청(500938)이 「작성」으로 남음. 발주는 「완료」.
- 자세히 = `../보관/화면별-요령/시험-생산-외주.md` 「납품창고 = 다음 공정 업체 창고 시험」.

## 5. 실제 입력으로 확인할 것 (차례대로, 첫 건은 화면 보며)
1. **엣지 납품이 되려면 재단품을 T이룸으로 옮겨야 한다** — 0015 는 이미 납품돼서 새 규칙이 안 먹는다. 사장님이 길을 정해야 시작: (가) 자재출고 202611100006 의 재공품 14줄 삭제로 요청 되살린 뒤 500938 → 500940 출고 (나) 요청 없이 500940 직접. **결정 없이 하지 않는다.**
2. 재단품이 T이룸에 들어온 뒤 **엣지 납품(0016)** — 납품창고가 T이룸 그대로라 엣지품은 T이룸 입고 → 보링 전에 T이룸 → T로앤 출고가 필요(0016 은 못 고쳤음). 확인: 출고 요청 202611100017 에서 엣지품 줄이 나오는지.
3. **보링 납품(0017, 납품창고 T조혼)** — 확인할 것: ① 저장되는지 ② 엣지품(_2)이 **T로앤 창고**에서 빠지는지(발주 업체 창고) ③ 완성 부속이 **T조혼 창고**로 입고되는지(501624 외주입고 창고 · 501179). 이것이 「마지막 공정 → 조립업체」 첫 실제 확인.
4. **조립 납품(0018)** — 출고 없이 T조혼 창고의 부속으로 투입되는지. 공통부속(p01·p02 엣지 끝, p04·p06 보링 끝)은 아직 T조혼 으로 안 감(0016 못 고침 · p04·p06 은 0017 로 감) — 막히면 어느 부속이 모자란지 문구 그대로.
5. **남는 출고 요청(「작성」) 영향** — 501622 외주입고정산처리에서 그 입고 건이 정상으로 잡히는지(⛔ 전표처리 누르지 않음, 조회만).
6. 새로 넣는 발주부터는 **처음부터 줄 납품창고 = 다음 업체**로 저장하고, 출고 없이 공정 납품이 끝까지 이어지는지 한 생산으로 확인(T 시험이면 끝나고 모두 지움 · 501179 대조).
