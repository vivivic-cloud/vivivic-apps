# 명세서 정리 — (주)엘데코 2026-01 (11-28 첫 판)

사장님 지시: 「보드엣지 매입현황 각 월별명세에 명세서 넣고, NAS 명세서를 하나씩 텍스트로 정리 + 사진은 눌러서 보이게, 각 월별명세랑 합계 확인」. 첫 판 = 엘데코 1월만.

## 자료 위치 (주소·가격·사진은 저장소에 올리지 않음)
- NAS 「거래명세서 모음/2026년/1월/(주)엘데코」 PDF(접속 주소·로그인은 사장님 쪽, 새 작업자는 사장님께 물어 크롬 로그인 탭으로). 월 폴더 → 업체 폴더 → `MM-DD(n)엘데코.pdf`. 1월은 PDF 23장 + 거래원장 사진 3개.
- 월별명세 = 드라이브 `관리프로그램/발주역입력/` TalkFile 구매내역서 엑셀의 「엘데코」 시트(3행 머리줄·4행부터 월별, 달마다 「[N월 소계]」).

## 방법
1. File Station 에서 첫 파일 클릭 → 맨 아래 파일 shift+클릭(전체선택 단축키는 안 먹음) → 우클릭 → 다운로드(zip). 2번에 나눠 받음.
2. zip 한글 이름은 `unzip` 이 깨짐 → Python `zipfile` 로 `MMDD_n.pdf` 영문 이름으로 풀기.
3. PDF = 스캔 이미지(글자 아님). `sips -s format png --resampleHeightWidthMax 1800` 후 `sips -r 270` 으로 세움. 품목·수량·날짜는 인쇄 글자, 단가·금액·합계는 손글씨. 3장은 위쪽이 빈 세로 스캔이라 아래쪽만 잘라 씀.
4. 눈으로 읽은 값 = (품목, 수량, 단가, 손글씨 금액). 검산: 수량×단가×1.1(부가세 포함) = 손글씨 금액, 줄 금액 합 = 합계.
5. 확인 화면(HTML 한 파일, 이미지 내장, 로컬): 읽은 값 옆에 손글씨 캡처(단가·금액 / 합계), 누르면 원본, 「패스」·「편집」 결정(브라우저 localStorage), 위에 월별명세 1월 품목별 대조 표.

## 결과(엘데코 1월)

- 확인 필요 3곳: ① 01-21(1) 손글씨 금액·합계가 계산값과 다름 ② 01-21(2) 인쇄 날짜 22일 → 손글씨 21일 정정 ③ 01-26(2) 발리오크 수량 70 → 손글씨 68 정정(월별명세도 68 기준과 일치).
