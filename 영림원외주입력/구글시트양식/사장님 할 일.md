# 구글시트 양식 연결 — 사장님이 한 번만 하실 일

컴퓨터(크롬)에서 하세요. 폰은 편집기가 불편합니다. 약 5분.
비밀번호는 누구에게도 주지 마세요. 구글 화면에서 사장님이 직접 누르시면 됩니다.

1. 크롬 주소창에 `script.new` 를 치고 엔터 → 사장님 구글 계정으로 새 스크립트가 열립니다.
2. 위쪽 「제목 없는 프로젝트」를 눌러 이름을 `영림원외주입력 양식만들기` 로 바꿉니다.
3. 아래 주소를 새 탭에서 열고, 보이는 글을 **전부** 복사합니다(⌘A → ⌘C).
   https://raw.githubusercontent.com/vivivic-cloud/vivivic-apps/main/%EC%98%81%EB%A6%BC%EC%9B%90%EC%99%B8%EC%A3%BC%EC%9E%85%EB%A0%A5/%EA%B5%AC%EA%B8%80%EC%8B%9C%ED%8A%B8%EC%96%91%EC%8B%9D/%EC%96%91%EC%8B%9D%EB%A7%8C%EB%93%A4%EA%B8%B0.gs
4. 스크립트 화면 가운데 글을 모두 지우고(⌘A → 지우기) 붙여 넣습니다(⌘V). 디스크 모양 「저장」을 누릅니다.
5. 오른쪽 위 파란 「배포」 → 「새 배포」 → 톱니바퀴 → 「웹 앱」.
   - 실행 계정: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   → 「배포」.
6. 「액세스 승인」 → 사장님 계정 고르기 → 「Google에서 확인하지 않은 앱」 화면이 나오면 「고급」 → 「(안전하지 않음)으로 이동」 → 「허용」.
   (사장님이 직접 만든 스크립트라 이 화면이 나옵니다. 드라이브 「영림원외주입력 양식」 폴더에 시트를 만드는 권한입니다.)
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 「복사」해서 바이글에게 보내 주세요.
   작업자가 폼에 그 주소를 넣으면 「양식 다운로드 → 구글 스프레드시트」가 됩니다.

## 이미 배포하셨다면 — 고쳐 올리기 (11-09, 주소는 그대로)
첫 배포에서 시트 만들기가 「drive」 오류로 막혔습니다. 드라이브 API 를 켜야 합니다. 한 번에 하나씩:
1. 그 스크립트 화면을 엽니다(script.google.com → 「영림원외주입력 양식만들기」).
2. 왼쪽 「서비스」 옆 **+** → 목록에서 **Drive API** 고르기(버전 v3) → 「추가」.
3. 위 3번 주소의 글을 다시 전부 복사해, 가운데 글을 모두 지우고 붙여 넣은 뒤 「저장」.
4. 오른쪽 위 「배포」 → **「배포 관리」** → 연필(수정) → 버전 「**새 버전**」 → 「배포」. (승인 창이 뜨면 6번처럼 허용)
   주소는 바뀌지 않습니다. 바이글에게 「다시 올렸다」고만 알려 주세요.

## 한 번 더 — 쓰기 권한 (11-09 두 번째)
Drive API 를 켠 뒤에는 「drive.files.create 을(를) 호출할 수 있는 권한이 없습니다」가 나왔습니다. 처음 승인 때 드라이브 「읽기」 권한만 받았기 때문입니다(코드에 읽기 함수만 보였음). 코드를 고쳤으니:
1. 위 3번 주소의 글을 다시 전부 복사해 붙여 넣고 「저장」.
2. 위쪽 함수 고르는 칸에서 `checkAccess` 를 고르고 「실행」 → 권한 창이 뜨면 **사장님이 직접** 계정 고르기 → 「고급」 → 「이동」 → 「허용」(이번엔 「드라이브의 모든 파일 보기, 수정, 생성, 삭제」가 보여야 합니다).
3. 「배포」 → 「배포 관리」 → 연필 → 버전 「새 버전」 → 「배포」. 주소는 그대로입니다.

## 알아 두실 것
- 이 스크립트는 폼에서 누를 때만 돕니다. 그 폴더에 새 시트를 만들기만 하고 다른 파일은 안 건드립니다. 하루 300장까지만 만듭니다.
- 연결 전에는 「구글시트 양식을 만들지 못했습니다. 「양식 다운로드 → 엑셀」로 받아 주세요.」가 뜹니다.
- 만든 시트를 올리기(「일괄 업로드 → 구글 스프레드시트」)할 때는 지금처럼 시트 「공유 → 링크가 있는 모든 사용자」를 켜 주세요.
- 끄고 싶으면: 스크립트 화면 「배포」 → 「배포 관리」 → 보관처리.
