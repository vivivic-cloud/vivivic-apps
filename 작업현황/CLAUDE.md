## 구조 (v1.2.0, 11-16)
- `index.html` — 화면. **읽기만** 한다. 보이는 것은 셋뿐: ① 사장님 확인할 것 ② 방별 한 일 ③ 마지막 갱신 시각(머리띠 오른쪽, 3시간 넘게 안 바뀌면 빨강).
  모양은 `조혼가구/재고관리.html` 의 머리띠·묶음·딱지 값 그대로(새 꼴 만들지 않음). 5분마다 `data.json` 을 다시 읽는다.
- `data.json` — 자료 한 벌. **손으로 고치지 않는다**(예약 작업이 덮어쓴다).
  `{ 갱신(ISO, +09:00), 확인:[{글, 방, 방링크, 일지링크, 화면링크, 화면이름}], 묶음:[{이름, 방:[{제목, 상태, 마지막, 한일, 링크, 화면링크, 화면이름}]}] }`
  상태는 `작업중` · `사장님 지시 대기` · `끝남` 셋뿐.
- 갱신 — Claude 데스크톱 앱의 **예약 작업 `작업현황 갱신`(taskId `work-status-refresh`)**(약 30분 간격). 앱이 켜져 있어야 돈다(꺼져 있으면 다음에 켤 때 돈다).
  `list_sessions`·`list_events` 로 방들의 최근 보고를 읽고 `data.json` 만 GitHub API 로 다시 쓴다(체크아웃·다른 파일 안 건드림).
  예약 작업의 지시문은 앱의 `~/.claude/scheduled-tasks/작업현황-갱신/SKILL.md`.

- `프로그램길.json` — 줄마다 붙는 **「그 프로그램의 해당 화면」 링크 표**(11-16). 프로그램별 첫 화면 + 주소로 열리는 부분(화면), 그리고 「연결불가」 목록·이유.
  예약 작업이 이 표에서 골라 `화면링크`·`화면이름` 을 채운다. `올리기.py` 는 **이 표에 없는 주소를 거부**한다(지어낸 주소 방지).
  줄 링크 순서는 화면 **[프로그램 해당 부분] → [일지] → [방]**(없는 것은 빠짐).

## 삭제 (v1.2.0, 11-16) — 사장님: 「모든 박스(줄)에 삭제 버튼 … 되돌릴 수 없습니다 확인창 … 되살아나면 안 됨」
- 줄마다(확인할 것·방별 한 일) **[삭제]** → 「삭제하면 되돌릴 수 없습니다」 확인창 → 확인해야만 지운다. 묶음(그룹) 머리에는 삭제가 없다.
- 웹페이지는 깃에 못 쓰므로 **파이어스토어 `artifacts/vivivic-4b7ef/public/data/ws_deleted/{종류}-{id}`** 에 **지문(해시)만** 적는다: `종류`(확인|방)·`id`·`방해시`·`보고해시`·`마지막`(방만)·`때`. **글·요약·링크는 어디에도 안 적는다.** 쓰는 곳은 이 칸 하나뿐(규칙: 익명 로그인이면 `public/data/*` 읽기·쓰기 가능 — 다른 칸과 같다).
- 화면은 지문이 맞는 줄을 **바로 뺀다**(열 때마다 `ws_deleted` 를 읽음).
- `data.json` 에서의 제거는 **`올리기.py 올리기`** 가 한다: 올리기 전에 `ws_deleted` 를 읽어(읽기만, 익명 열쇠를 `~/.claude/작업현황-열쇠.json` 에 돌려 씀 — 저장소에 안 올림) ① 줄마다 `id`(해시)·`방해시` 를 붙이고 ② 지운 줄을 빼고 ③ 올린다. **못 읽으면 올리지 않는다**(되살아남 방지).
- 되살아남 방지 규칙: 확인 줄은 `id` 가 같거나, **같은 방 + 같은 보고 글(`보고해시`)** 이면 다시 안 만든다(예약 작업이 글을 다르게 써도 막힘). 방별 한 일 줄은 지운 뒤로 방이 **더 최근에 움직이면**(마지막 시각이 더 새로우면) 새 일이라 다시 보인다 — 그 규칙은 화면 `지웠나` 와 `올리기.py` 에 같은 모양으로 있다.
- 지운 줄의 글은 **현재 `data.json`·파이어스토어에서는 사라지지만 깃 과거 커밋에는 남는다**(히스토리는 안 고친다 — 사장님 판단 사항). 이 화면을 연 뒤 갱신(≤30분)이 돌기 전까지는 `data.json` 파일 자체에 아직 있을 수 있다(화면에서는 이미 안 보임).
- 시험(11-16): 시험 항목으로 삭제·새로고침·갱신 뒤 안 돌아오는 것을 확인. 시험이 남긴 `ws_deleted` 문서는 해시뿐이다.

### 해당 부분 연결 불가 (사장님 확인 전 다른 프로그램 코드는 안 고침)
- **영림원 입력폼 안의 메뉴(발주 등록·세트구성품등록 등)** — 폼이 단계마다 `#키` 를 바꿔 쓰지만 **켤 때 지운다**(`영림원외주입력.html` ~8482줄, v256 사장님 「처음 열면 메뉴만」, 메모 「폼 밖에서 #… 로 여는 링크 없음(임시)」). 라이브에서 `…html#setitems` 로 열면 `#setitems` 가 지워지는 것까지 확인. 열려면 그 폼 코드를 고쳐야 한다 → **사장님 결정 필요**.
- **에이엠티** — `?명세=<큐알 글>`(특정 납기 명세서) 하나뿐. 일반 화면 방식 없음.
- **조혼가구·원장관리·작업지시서** — `#`·`?` 로 화면을 고르는 코드 없음.
- **하우저·벤더피아의 특정 상품·주문** — 화면(메뉴) 단위까지만. 벤더피아 단품관리 `#vp-q=검색어` 는 검색어 칸을 채울 뿐이라 자동으로 쓰지 않는다.
- **바이글 박스·SystemCloud 메뉴** — 주소로 여는 길을 못 찾음.

## ⚠ 지킬 것
- **공개 저장소다.** `data.json` 에는 **업체명·금액·전화·주소·비밀번호·원장 내용을 쓰지 않는다.** 한 줄 요약(무엇을 했나)만.
- 화면에 공정·업체·발주 같은 **상세 줄을 미리 나열하지 않는다.** 요약만.
- 「방 열기」 링크는 `claude://claude.ai/epitaxy/local_…` — 이 맥(앱이 깔린 기기)에서만 열린다. 폰에서는 안 열린다.
- 저절로 도는 것 금지 규칙(10-17 쓸기·감시 삭제)이 있었으나, 이 예약 작업은 **11-15 사장님이 직접 시키셨다**(B방식).
- 기능을 늘리지 않는다(비용 등은 사장님이 따로 시키실 때).
