# 조혼가구 시험

`조혼가구.html` 을 진짜 크로미움으로 열어 **폰 375px 에서 손가락으로 눌러 보는** 시험입니다.
앱에는 아무 영향이 없습니다 — GitHub Pages 는 `조혼가구.html` 만 내보냅니다.
이 폴더를 통째로 지워도 앱은 그대로 돕니다.

## 돌리는 법

    cd <저장소>/조혼가구/tests
    node 도구/다돌리기.mjs        # 전부 — 통과·떨어짐과 못 수를 세어 준다 (목록 파일 없이 tests/*.mjs 를 다 돈다)
    node 명세표1.mjs              # 하나만

**미리 띄울 서버도, 미리 받을 것도 없습니다.** 시험이 스스로 8899 에 자리 서버를 띄우고
(이미 저장소를 8899 에 내주는 것이 떠 있으면 그것을 씁니다), 처음 한 번만
`tests/.자재/` 에 테일윈드를 받아 `조혼가구.html` 기준으로 CSS 를 뽑습니다.
`.자재/` 와 시험이 찍는 `.그림/` 은 저장소에 안 들어갑니다.

플레이라이트와 크로미움은 에이엠티 시험과 **같은 것**을 씁니다
(`에이엠티/tests/도구/터.mjs` 를 가져다 씁니다 — 두 집의 틀이 갈라지지 않게).

| `큐알길1` | 규칙표로 무엇인지 가린다 · 모르는 글은 그대로 보이고 한 줄 · 규칙표가 비거나 못 읽어도 안 터진다 |

| `두루1` | 새 화면을 붙여도 옛 화면 다섯 칸이 **가로로 안 밀린다** |

## 못 재는 것 (그대로 적습니다)

- **진짜 카메라**가 없습니다. `getUserMedia` 를 허수아비로 꽂아 차례와 끄기만 잽니다.
- **진짜 화베**에 못 씁니다. `getDoc`·`setDoc`·`runTransaction` 을 허수아비로 꽂아
  **무엇을 읽고 무엇을 쓰려 했는지**만 잽니다. 진짜로 들어가는지는 사장님 폰에서만 확인됩니다.
- 바깥 CDN(`unpkg`·`cdn.tailwindcss.com`)이 막힌 자리에서 돕니다.
