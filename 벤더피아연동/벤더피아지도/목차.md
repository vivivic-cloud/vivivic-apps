# 벤더피아 지도 — 목차

확인한 날: 2026-11-07 · 화면 38개 (확인함 37 · 일부 1 · 미확인 0)

**벤더피아연동을 고치기 전에 이 쪽부터 본다.** 화면을 다시 뒤지지 말고 아래에서 찾아 그 화면 파일을 읽는다. 실제 화면이 지도와 다르면 지도를 고친다.

- 모든 화면이 같이 쓰는 틀·함수·요청 규칙: [공통](공통.md)
- 사람이 보는 검색 쪽: https://vivivic-cloud.github.io/vivivic-apps/벤더피아연동/벤더피아지도/
- 상태 뜻: 확인함 = 실제 화면을 열어 구조를 읽음 / 일부 = 일부만 읽음(까닭은 그 파일에) / 미확인 = 못 읽음
- 구분 뜻: 조회 · 내려받기 · 이동 · 팝업 · 출력 · 화면만 · 쓰기 · 미확인. **눌러 보지 않고 소스로만 가렸다.** 「폼 제출(서버 처리)」 는 서버가 무엇을 하는지 눈으로 확인하지 않았다는 뜻이다.
- 거래처·몰·사람 이름 같은 업무 자료, 고객 정보, 계정 값은 적지 않는다. 공개 저장소다.
