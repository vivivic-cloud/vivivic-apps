# 공통 — 모든 화면이 같이 쓰는 것

확인한 날: 2026-11-07. 실제 화면과 벤더피아 공용 글(`/js/common.js`·`/js/commonJQ.js`·`/js/accountGuard.js`·`/js/vpCookie.js`)을 읽어 적었다.

## 틀

- 로그인 뒤 맨 위 문서는 `/index.aspx`. 왼쪽 메뉴와 머리 단추가 있고, 화면은 `iframe#icontentFrame` 안에 뜬다. (⚠ `벤더피아연동/CLAUDE.md` 의 「메인은 frameset」 설명과 다르다. 2026-11-07 원래 화면에서 재면 `<body>` + `iframe#icontentFrame` 이다.)
- 메뉴 단추: `GoUrl(주소, 메뉴id)` = `$('#icontentFrame').attr('src', 주소)` 후 왼쪽 메뉴 불을 옮긴다. 쪽 전체는 안 바뀐다.
- 머리 단추(jQuery click, `index.aspx`): `#lnkOrderUpload` 주문등록 → `System/Upload/oRowInsert.aspx` · `#lnkOrderProcess` 주문확정 → `System/Sales/confirmOrder.aspx` · `#lnkDeliveryReg` 송장등록 → `System/Delivery/confirmDv.aspx` · `#lnkCSReg` CS등록 → `System/CS/csDetl.aspx?previousPage=first` · `#lnkKakaoAmt` 잔액 → `/System/Kakao/ChargeHistory.aspx` · `#newTab` 새탭(지금 주소를 새 탭) · `#lnkHelp` 도움말 · `#lnkUserMsg` 관리자 메시지(서랍) · `#btnLogout`·`#btnMLogout` LOGOUT → `LogOut.aspx`.

## 쪽의 꼴

- ASP.NET WebForms. 폼은 거의 `form#aspnetForm` 하나, POST 자기 주소, 칸 이름 앞머리는 `ctl00$Contents$`.
- 숨은 값 공통: `__EVENTTARGET` · `__EVENTARGUMENT` · `__VIEWSTATE` · `__VIEWSTATEGENERATOR` · `__EVENTVALIDATION` · `ctl00$hdKey` · `ctl00$hWidth` · `ctl00$hMobile` · `oGrid_clientState`.
- 조회 단추는 대개 `input[type=image]#btnSearch`(`icon_hit.gif`) 로 **폼 제출**이다. 요청에 `ctl00$Contents$btnSearch.x/.y` 가 붙는다. 엑셀은 `#btnExcel`, 쪽 넘김은 `#Pager1`(`__doPostBack('ctl00$Contents$Pager1$ctl…')` 와 Next·Last 그림 단추).
- 쪽당 줄 수 `ddlRowCnt`: 고르면 바로 다시 조회한다(`__doPostBack` 또는 `$('#btnSearch').click()`).
- 화면마다 `jScript()` 함수에서 jQuery 로 단추에 click 을 단다. 그래서 `onclick` 속성만 봐서는 동작을 모른다. 이 지도의 「동작」 칸은 달린 jQuery 처리 글까지 읽은 것이다.
- UpdatePanel 이 있는 화면은 조회가 부분 다시 그리기다. 각 화면 파일의 「비동기」 줄을 본다.
- `$('#aspnetForm').submit` 이면 `#divloading`(돌림 표시)을 켠다. `excel` 속성이 있는 단추는 켜지 않는다.
- 달력 칸은 Infragistics 공용 달력(`table#ctl00__ig_def_dp_cal.igmc_Control`)을 같이 쓴다. ⚠ 표를 찾을 때 이 달력을 목록으로 잡지 마라.

## 그리드 (Infragistics WebDataGrid)

- `div#oGrid.ig_Control.igg_Control`. 머리와 몸이 서로 다른 `table` 이다.
- 자바스크립트로 `$find('oGrid')` → `.get_columns()`(`get_key`·`get_headerText`·`get_hidden`) · `.get_rows()`(`get_row(i)`·`get_cellByColumnKey(열키)`) 로 읽는다. 화면 파일의 열 이름은 `머리글(열키)` 꼴이다.
- 숨은 열은 사용자 칸 설정으로 바뀔 수 있다. 박지 말고 그때그때 `get_hidden()` 또는 머리 th 의 computed display 로 가른다.
- 줄 누름: 많은 화면이 `oGrid_CellSelectionChanged` 로 상세 화면에 간다. `CHK` 칸을 누른 것이면 가지 않는다.
- 체크: `CHK` 열. 줄 안 체크상자는 대개 `ctl00$Contents$oGrid$it…$chkItem`. 머리 `chkALL` = `CheckAllChkItems(this)`.
- ⚠ 체크가 바로 서버로 가는 화면이 있다(csDetl 의 주문 그리드 등). 화면 파일을 보고, 모르면 체크하지 마라.

## 화면 사이 이동

- `SetSearchCondition(주소)`: `#divSearch`·`#divCondition` 안의 칸 값과 `hdCurrentPage` 를 `▥` 로 이어 `?SearchCondition=…` 로 붙인다. 상세에서 돌아올 때 `ReturnSearchCondition(주소)` 가 그대로 돌려준다.
- 팝업: `fnShowPopup()` = `#iFramePopup` 에 `src` 를 넣은 뒤 `#dialogPopup` jQuery UI 대화창(너비 1250). `fnShowModal(제목, 주소, 크기)` = `#modalPopupiFrame` + 부트스트랩 모달. `window.open` 팝업도 있다.
- `sendPost(action, params)`: 숨은 폼을 만들어 POST. `sendPrint(action, params)`: `PrintViewer` 창에 POST(출력).
- 값을 고르는 팝업은 부모의 `getReturnValue` 를 부른다(`ordersPopup.aspx` 등).

## 계정·세션

- 쿠키 `VP_Cookie` 는 값 단위 암호화. `getServerCookie('VP_Cookie', 'LOGON_EMP_VCD')` 등이 `vpCookie.js` 로 푼다.
- `accountGuard.js`(2026-10-13): 브라우저당 한 계정. 쪽의 `window.VP_PAGE_ACCOUNT` 와 쿠키를 비교해 다르면 index 를 다시 연다.
- 벤더피아는 한 로그인의 요청을 하나씩 처리한다(ASP.NET 세션 잠금). 잰 값은 `벤더피아연동/CLAUDE.md` 의 「이동 느림」 쪽. 뒤에서 요청을 겹쳐 보내면 사람 화면이 밀린다.

## 다시 재는 법

- 확장 없는 원래 화면: 새 탭에서 `window.name="vp원본"; sessionStorage.setItem("vp원본","1"); location.reload()`.
- 이 지도는 그 탭에서 각 화면을 `sandbox="allow-same-origin allow-scripts"` iframe 으로 열어 읽었다. allow-forms·allow-modals·allow-popups 가 없어 폼 제출·알림창·새 창이 원래부터 막힌다. **단추를 하나도 누르지 않았다.**
- 재기 전 메뉴: 왼쪽 메뉴 a 의 `onclick="GoUrl(…)"` 전체.
