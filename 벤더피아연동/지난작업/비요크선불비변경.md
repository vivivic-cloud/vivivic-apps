# 지난작업 — 비요크선불비변경 (2026-11-25, 0.35.11~0.35.20)

메인 「지난작업보기」 안에 있는 **일회성 메뉴**. 다음에 비슷한 일(파일에 적힌 값으로 벤더피아 주문을 여러 건 고치기)이 생기면 이 글과 코드를 꺼내 고쳐 쓴다.
자세한 잰 값·함정 원문은 `../CLAUDE.md` 「비요크선불비변경」 절에 있다. 이 글은 그 요약과 다시 쓰는 법이다.

⚠ 공개 저장소다. 고객명·전화·주소·주문번호·송장번호·매출처코드·vendorCd·아이디·쿠키·`__VIEWSTATE`·거래처 금액은 이 글·코드·시험에 **절대 넣지 않는다.**

## 1. 무엇을 했나 (목적)

사은품 **비요크 박스형 협탁**의 주문 선불배송비가 처음 단가로 잘못 들어가 있었다 → 사장님이 고칠 주문 목록 파일을 주셨고, 그 줄들의 벤더피아 주문 선불비를 **5,000원으로 일괄 수정**했다.
- 첫 지시(그대로): 「메인에 이파일을 목록화한 페이지 만들어줘 - 메뉴이름 비요크선불비변경」
- 저장 지시(그대로, 0.35.14): 「체크된 주문은 해당목록의 선불비수정 값으로 해당 연결된 주문관리 목록의 선불비를 수정해야 합니다. …」 (전문은 CLAUDE.md)
- 파일 151줄 — 2026-11-25 벤더피아 주문관리 목록 선불비 = 「선불 수정」 **151/151 확인**(0.35.20 재기, 읽기만). 0.35.20 배포본에서 화면도 **연두 151 · 노랑 0**(다시 조회 32.9초, 새로고침하면 조회 0) — **일 끝남.**

## 2. 입력 파일 꼴

- **배송관리 내려받기 .xlsx 그대로 + 맨 뒤 「선불 수정」 칸** (원 파일은 구글 드라이브, 사장님이 톡으로 받은 것).
- 첫 시트 · 앞 20줄 안에서 「주문번호」·「선불비」 가 든 줄 = 제목줄. 그 위 글 = 메모(표 위에 그대로 보임). 그 아래 글 있는 줄 = 목록(꼴만 있는 빈 줄은 뺌).
- 칸 이름은 앞뒤 빈칸만 뗀다(「선불 수정 」 → 「선불 수정」). 숫자 「15000.0」 → 15000.
- 쓰는 칸: 「주문번호」(몰 주문번호) · 「송장번호」 · 「주문등록일」(조회 기간) · 「선불 수정」(넣을 금액).
- **고객 자료는 저장소에 없다.** 파일은 그 화면 「파일 올리기」 로 올리면 브라우저 안에서만 읽고, 그 브라우저 localStorage `vp비요크`(벤더피아 주소 쪽)에 기억한다. 다른 컴퓨터는 다시 올려야 한다. 「지우기」 = 그 기억 지움.

## 3. 흐름 (화면에서)

1. 메인 → 「지난작업보기」 → 「비요크선불비변경」 (새 탭 `orderMst.aspx#vgByk`)
2. **파일 올리기** → 표(CS등록 표와 같은 꼴, 바탕 흰색, 맨 앞 체크 칸·머리 = 전체 체크/해제)
3. **송장번호로 주문관리 연결**: 줄의 「주문번호」로 주문관리를 조회(조회 폼에 송장번호 칸이 없어서) → 받은 줄 중 「송장번호」 가 파일 송장과 같은 줄과 잇는다 → **노랑**. 같은 주문번호는 한 번만 묻는다. 기간 = 파일 「주문등록일」 가장 이른 날 −7일 ~ 오늘(주문번호 조회도 등록일 기간에 걸림).
4. 고칠 줄 **체크** → **저장** → 확인 창 → 한 줄씩 저장, 단추 밑에 「저장 중 k/n · 단계」 → 끝나면 현황(저장됨·이미 같음·실패·까닭).
5. 확인되면 **연두**. 0.35.20 부터 연두 = 이은 주문관리 목록 「선불비」 = 그 줄 「선불 수정」(누가 어디서 저장했든). 다시 열면 기억한 색으로 먼저 칠하고 연두 아닌 줄만 다시 묻는다.

## 4. 벤더피아 쓰기 길 (벤더피아 쓰기 예외 다섯 번째)

- 주문 여러 건을 한 번에 고치는 화면은 없다 → **한 건씩 연속**, 실패하면 그 자리에서 멈춤.
- **주문 상세** = `orderDetl.aspx?orderNo=…&sCd=…&sNm=…&sGoodsCd=…&vendorCd=…` — **다섯 값이 다 있어야** 내용이 찬다.
  - orderNo(안 번호 = 목록 「주문번호」 앞 칸)·sCd(매출처코드)·sNm(매출처)·sGoodsCd(상품코드) = 주문관리 조회 응답 `#oGrid` 69칸에서.
  - vendorCd = **로그인 쿠키** `getServerCookie('VP_Cookie','LOGON_EMP_VCD')` (응답 글에는 없다 — 0.35.18 에서 고침). 값은 코드에 안 박는다.
- **배송정보** 섹션 = Infragistics 그리드 `dGrid`. 칸 key `deliveryCost`(선불비) · `invoiceNo`(송장번호). invoiceNo = 송장인 줄 **하나**의 deliveryCost 셀에 `set_value(금액)`. (옛 글칸 `tbDeliveryCost` 는 지금 없다.)
- **저장** = 위 그림 단추 `btnSave`.click() → 폼 전체 제출. ⚠ 벤더피아 손잡이가 `getGridInfo` 없음 오류를 늘 내지만 제출은 나간다(사람이 눌러도 같음). 값은 제출 때 Infragistics 가 `dGrid_clientState` 에 싣는다.
- **숨은 틀**: 화면 밖 iframe `sandbox="allow-same-origin allow-scripts allow-forms"`(allow-modals 없음 → 알림 창 안 뜸, alert·confirm 가로챔).
- **공용 줄 잡기**: `VP_DATA.잡기(일)` 로 상세 열기~확인 동안 이 문서의 다른 벤더피아 요청을 멈추고, 다른 우리 탭 뒤 요청도 15초 쉼(`VP원본쉼`). 벤더피아는 한 로그인의 요청을 하나씩 처리해서 끼이면 늦어진다.
- **60초**: 제출 뒤 답을 60초까지 기다린다(틀을 지우면 요청이 끊겨 저장이 안 된다 — 0.35.18 의 4초가 그 탈). 답이 오면 상세를 **새로 열어** 선불비가 금액인지 읽어 확인.
- 코드: `../비요크.js` (`주문묻기` · `선불비저장한줄` → `상세저장` · `완료판정`) · 쪽 틀·표·고름 칸 `../search.js` `비요크보기` · 공용 줄 `../vp-data.js` `잡기`.

## 6. 겪은 문제와 고친 것

- **저장 눌러도 무반응**(0.35.16): 안내 글이 단추에서 먼 회색 칸에 떴다 → 단추 밑 현황 칸.
- **「여는 값을 못 읽었습니다」**(0.35.18): vendorCd 를 응답 글에서 찾았는데 없었다 → 로그인 쿠키에서.
- **「저장이 안 됐습니다」**(0.35.19): 제출은 나갔는데 4초 안에 답이 없어 틀을 지우며 요청을 끊음 → 공용 줄 잡기 + 60초 + 다시 열어 확인.
- **남이 저장한 줄이 노랑**(0.35.20): 연두가 저장한 브라우저 기억에만 있었다 → 주문관리 목록 선불비로 판정(목록 값 = 상세 dGrid 값, 14줄 재서 같음).
- ⚠ 주문관리 조회 폼엔 **송장번호 칸이 없다** — 주문번호로 묻고 송장으로 고른다.
- ⚠ Chrome 도구가 응답의 `orderDetl` 주변 글을 「Cookie/query string」 으로 막는다 — 우회하지 않았다.
- ⚠ 제출 내용을 capture 단계에서 막으면 값이 안 실린 것처럼 보인다 — 거품 끝에서 본다.

## 7. 비슷한 일에 다시 쓸 때 바꿀 곳

1. **메뉴**: `../menu.js` `지난작업` 에 한 줄(새 이름·새 `#vg…` 꼬리) — 또는 이 메뉴를 그대로 쓰면 「지우기」 뒤 새 파일만 올린다.
2. **파일 칸 이름**: `비요크.js` 의 「선불 수정」(넣을 값 칸) · 「선불비」(제목줄 찾기) · 「주문번호」 · 「송장번호」 · 「주문등록일」. 새 파일 칸 이름이 다르면 여기만.
3. **금액**: 코드에 5,000 을 박지 않았다 — 줄마다 파일 「선불 수정」 값을 넣는다. 다른 금액이면 파일만 바꾼다.
4. **상품**: 코드는 상품을 가리지 않는다 — 파일에 든 줄만. 다른 상품이면 그 상품 줄 파일을 올린다.
5. **저장할 칸**: 선불비 말고 다른 값이면 `상세저장` 의 `dGrid` 칸 key(`deliveryCost` → 예 `postPayment`)와 완료 판정의 목록 칸 이름(「선불비」)을 바꾼다. 주문 상세 다른 섹션이면 그 그리드를 원래 화면에서 **먼저 열어 보고**(CLAUDE.md 루트 규칙: 실제 화면 확인) key 를 옮긴다.
6. **쪽 이름·기억 열쇠**: 새 메뉴로 갈라 낼 때는 `#vgByk`·`vp비요크`·`vp열넓이:비요크`·h1 글을 새 이름으로(옛 기억과 섞이지 않게).
7. **시험**: `../잰것/비요크.cjs`(지어낸 자료만) — 흉내 주문관리·상세 그대로 쓰고 칸 이름만 바꾼다.
8. ⚠ 벤더피아에 쓰는 일이다. 처음엔 **한 줄만** 체크해 저장해 보고, 주문관리에서 값을 확인한 뒤 나머지를 한다.
