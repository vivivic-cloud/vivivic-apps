# 벤더피아연동 — 이 집에서 지킬 것

벤더피아(`https://vendorpia.com`, ASP.NET WebForms ERP) 위에 덧씌우는 **크롬 확장 프로그램**이다.
웹 앱이 아니다. 벤더피아의 **진짜 아이디·비밀번호로 그 사이트 로그인을 그대로** 쓴다
(집 이메일 로그인을 쓰는 「배송관리업로드」 와는 다른 것이다). 크롬이 깔린 컴퓨터에서만 돈다 — 폰에서는 안 된다.
설치 안내는 이 폴더의 `index.html` (https://vivivic-cloud.github.io/vivivic-apps/벤더피아연동/) 이다.
확장 이름(manifest)은 「벤더피아 보기」, 사장님 컴퓨터 원본 폴더는 `~/Desktop/벤더피아보기` 다 (크롬이 거기서 읽는다).

## 목록 화면이 하는 일 (`goods.js`)

⚠ 10-21 부터 **표**다 (사장님: 「단품관리와 상품관리 재고조회의 각 버튼이 메인이 되는 표형식으로 나열해줘」).
- **첫 칸 = 이름 버튼**(누르면 오른쪽에 상세 창). 나머지 칸은 `vp-data.js` 의 `PAGES[…].cols`:
  단품관리 `단품분류·현위치(매입처명)·재고유형·발주유형·판매상태` / 상품관리 `매출처·매입처명·배송사명·판매상태·옵션상품유무·상품정보(링크)` /
  재고조회 `분류명·현위치·양품수(합)`. **금액 칸은 표에도 안 꺼낸다.**
- **이름 하나에 표 줄 하나.** 같은 단품·상품의 줄이 여럿(창고별·매입처별·매출처별)이어도 한 줄이고, 칸에는 값들을 **중복 없이 모아**
  적는다(셋 넘으면 「… 외 N」, 마우스를 올리면 전부). 줄은 `groups`(이름 → `{b, items, tr, tds, i}`)가 하나씩 들고 있다.
- **거르개 알약**(검색칸·선택칸 **아래** `.vp-pillbar`): `PAGES[…].pill` — 단품관리 **현위치 = 매입처명**(예전 [전체보기][현위치별 보기] 탭을 없앴다),
  상품관리 **매출처명**, 재고조회 **현위치 = 창고, 창고가 0.본사면 매입처**(상세의 현위치 탭과 같은 논리, `placeIn`).
  알약을 고르면 그 값이 든 줄을 하나라도 가진 이름만 남고(`matches` 의 `pillPick`), 줄은 그대로 한 줄이다. 칸도 **고른 값의 줄만** 모아 적는다
  (재고조회 양품수 = 고른 현위치 것만의 합). 알약에는 그 값이 든 이름 수가 붙는다. 상세 창도 고른 값부터 연다(상품 상세의 매출처 알약·재고 상세의 현위치 탭).
  상품관리의 선택칸 「매출처」·단품관리의 「매입처」 선택칸은 알약과 겹쳐 **없앴다**.
- 표 줄 차례: 첫 화면은 **최근 3개월 많이 나간 순 50개**(「더보기」·「전체보기」·「접기」 그대로). 표 줄에는 CSS `order` 가 안 먹어
  `reorder()` 가 줄을 **실제로 옮긴다**(이미 그 차례면 안 건드림).
- **이름은 버튼이 아니라 누르는 글자 + 아래 점 넷**(10-22 `[새 지시 연동 점]`). 글자 꼴은 서류관리의 누르는 글자(`text-info` `#337ea9`·평소 밑줄 없음·올리면 밑줄)를 따르고 표 안에서는 첫 칸 꼴(14px·700, 10-23)(상세 칩 12px), 누른 것은 굵게+밑줄. 버튼은 그대로 `td > div.vp-goods-list > button`(클래스 이름·시험 열쇠 유지).
  점은 글자 아래(`span.vp-점` 안 `i.g/.r/.o/.b` 넷, **클래스만 보고 CSS 가 켠다**): 🟢 초록 = 재고조회 목록에 있음(`vp-instock`, 양품 0 이어도) · 🔴 빨강 = 조혼가구와 일치(`vp-johon`, `markJohon`) · 🟠 주황 = 카탈로그 inghome 와 맞음(`vp-ing`, `ing맞춰보기`, 상품관리). 🔵 파랑 = 서류관리 연결(`vp-서류`, `서류연결` 판단 그대로, 색은 아래 팔레트, 10-22 `[새 지시 파란 점]`) · 해당하는 것만 나란히. 양품 딱지는 글자 곁에 그대로. 판단 논리는 안 바꿨다. 세 화면 머리(`h1` 아래 `.vp-legend`)에 점 설명 넷(● 서류관리 연결 포함).
  **점 색 = 사장님 팔레트**(10-22 `[새 지시 점 색]`, 사장님 말씀 「각 점을 이색상들로 사용해줘」): `#06AED5` Turquoise Surf · `#086788` Cerulean · `#F0C808` Bright Amber · `#FFF1D0` Papaya Whip · `#DD1C1A` Primary Scarlet. 짝(바이글이 정함) — 재고조회 🟢→`#06AED5`(`--점-재고`) · 조혼가구 🔴→`#DD1C1A`(`--점-조혼`) · 카탈로그 🟠→`#F0C808`(`--점-카탈로그`) · 서류관리 🔵→`#086788`(`--점-서류`). 네 CSS 변수는 `goods.css` 의 `#vp-root { … }` 한 줄에 모여 있다(점과 머리 설명이 같이 따라옴) — 바꾸려면 거기만. Papaya Whip 은 흰 바탕에서 점으로 안 보여 안 썼다. 점 크기·자리·기준은 그대로. ⚠ `#F0C808` 은 밝아 6px 점이 흰 바탕에서 옅다.
  ⚠ 서류관리 연결(`vp-서류`, `서류연결`, 수입정보 차수 박스)은 판단·기능 그대로, **주황 칠은 뺐고 파란 점으로 보인다**(단품 글자·상세 칩 어디서나) — 주황은 이제 카탈로그다. (10-24 에 배송관리·CS등록 상품명/단품명 단추도 같은 꼴로 바뀜 — 아래 「알아낸 것」 0.34.50. 옛 알약 꼴·서류 주황 칠 CSS 는 지움.)
- 속성은 **상세 창 안에서만**(전과 같다): 빈 값은 「전체속성 보기」, 금액 칸은 「금액속성 보기」(누르면 「금액 속성은 승인된 아이디만 볼 수 있습니다.」 팝업),
  조혼가구 단품은 「부속보기」(에이엠티 부속카드). **승인된 아이디는 아직 하나도 없다.**
- 표 꼴은 **서류관리 제품관리 박스의 표**(`vivivic-docs/index.html` `#docs-prod .dpr-t`)를 따른다(10-23, 아래 「표 꼴 = 서류관리 제품관리 표」 숫자 표). 좁은 창은 표 통만 옆으로 밀린다(쪽은 안 밀림). 첫 칸은 밀어도 왼쪽에 붙는다.
- 버튼에 코드를 작게 함께 적는다. 단품명에 `(사용안함)` 이 든 단품은 줄을 만들지 않는다.
- **재고는 단품으로만 관리한다** (상품은 판매명일 뿐). 재고조회에 있는 단품은 초록 점 + 양품수 딱지.
- 조혼가구 단품(모든 거래처 탭의 ING단품명)과 같은 단품은 이름 밑에 **빨간 점**. 붉은 줄 단품은 「부속보기」 →
  에이엠티 발주확정 부속카드 모양. AMT 부속은 붉게. 카드를 누르면 엣지 도면(초록선=엣지면, 붉은선=우라홈)과
  재단도면(조각마다 치수, 「+전도방지」).
- 상품 상세에는 연결된 단품 버튼, 단품 상세에는 연결된 상품 버튼. 상품정보(inghome) 링크는 표의 「상품정보」 칸과 상세 둘 다에 있다.

## ⚠⚠ 벤더피아 메인은 **틀(frameset)** 이다 (10-13)

사장님: 「메인화면에서는 **영역만 짚어지고** 지시내용을 보내는 부분이 안나타난다」 ·
「본 메뉴에 들어가서도 안된다」.

까닭 둘 —
1. 틀 문서에는 몸(`body`) 자리에 `<frameset>` 이 있다. **거기에 붙인 것은 안 그려진다.**
   붉은 테만 남아 「영역만 짚어진다」 로 보였다.
2. 확장 글은 기본으로 **맨 위 문서에서만** 돈다(`all_frames` 없음). 진짜 화면은 **틀 안쪽**이라
   거기엔 손잡이가 아예 없었다.

→ `불러오기.js`·`짚개.js` 둘 다 **`all_frames: true`**, 그리고 **틀 문서(`FRAMESET`)에서는 돌지 않는다.**
→ `짚개.js` 는 `불러오기.js` 에서 떼어 **제 content_script** 로 두었다(틀 안쪽까지 가야 한다).
⚠ 새 글을 붙일 때 이 둘을 꼭 지켜라. 안 그러면 또 「영역만 짚어진다」 가 난다.
