# 벤더피아ERP연동 — 이 집에서 지킬 것

벤더피아(물류) → 영림원 ERP(아이앤지홈) **송신 매핑 설계서를 보는 화면**이다. 읽기만 하는 정적 페이지 — Firebase·로그인 없음.
주소: https://vivivic-cloud.github.io/vivivic-apps/벤더피아ERP연동/벤더피아ERP연동.html

- 파일 — `벤더피아ERP연동.html` 하나. 자료는 그 안 `const DATA` (시트 11개 = 엑셀 설계서 v0.3 와 같은 내용). 판 번호는 머리띠 배지와 파일 맨 위 주석 둘 다(v0.3.1).
- 꼴 — 조혼가구·에이엠티와 같은 한 벌: Tailwind CDN + `shared/조혼가구모양.css`(머리띠·page-tab-link·notion-card), 표는 **벤더피아연동 `goods.css` 「표 꼴 = 서류관리 제품관리 표」** 숫자 그대로(머리 13px·800·2px 밑선, 몸 14px·47.8px). 행 색: 노란=확정 필요 · 회색=ERP 공통 컬럼 · 주황=벤더피아에 대응 칸 없음(「상태」 칸으로 칠한다).
- 찾기 칸 — 모든 시트를 뒤져 맞는 시트로 넘어가고 맞는 줄만 남긴다.
