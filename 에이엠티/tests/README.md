# 에이엠티 시험

`에이엠티.html` 을 진짜 브라우저(크로미움)로 열어 **폰 375px 에서 손가락으로 눌러 보는**
시험 47개입니다. 앱 화면에는 아무 영향이 없습니다 — GitHub Pages 는 `에이엠티.html` 만
내보냅니다. 이 폴더를 통째로 지워도 앱은 그대로 돕니다.

## 돌리는 법

    # 저장소를 받은 자리에서
    cd <저장소>/에이엠티/tests
    node boxes1.mjs            # 하나만
    node 도구/다돌리기.mjs      # 47개 전부 — 통과·실패를 세어 준다

**미리 띄워 둘 서버는 없습니다.** 시험이 스스로 8899 에 자리 서버를 띄웁니다
(이미 저장소를 8899 에 내주는 것이 떠 있으면 그것을 씁니다).

**미리 받아 둘 것도 없습니다.** 처음 한 번만 시험이 `tests/.자재/` 에
`tailwindcss · xlsx · sortablejs · gsap` 를 npm 으로 받고 테일윈드를 뽑습니다(40MB, 1분쯤).
그다음부터는 그대로 씁니다. `.자재/` 는 저장소에 안 들어갑니다.

플레이라이트만 있으면 됩니다. 없으면:

    npm i -D playwright && npx playwright install chromium

## 왜 이 세 가지가 필요한가

1. **자리 서버** — 앱이 한 파일(`에이엠티.html`)이라 `file://` 로 열면 못 하는 것이 있습니다.
   `도구/터.mjs` 가 저장소를 그대로 8899 에 내줍니다.
2. **자재(`.자재/`)** — 이 상자에서는 `cdn.tailwindcss.com` · `cdn.sheetjs.com` ·
   `cdn.jsdelivr.net` 에 못 닿습니다. 그래서 npm 으로 받은 **같은 판**을 시험 창에만
   끼워 줍니다(`ctx.route`). **앱 파일은 한 글자도 안 건드립니다.**
   CDN 에 닿는 자리에서 돌린다면 이 끼우기는 그냥 지나가도 그만입니다.
3. **자료** — 아래를 보십시오.

## 시험이 먹는 자료

시험은 자료를 **파일에서 바로 읽습니다**(서버로 긁지 않습니다). `도구/터.mjs` 의
`자료(이름)` 이 두 자리를 차례로 봅니다.

| 차례 | 자리 | 무엇 |
|---|---|---|
| ① | 저장소 뿌리 `원장.json` · `confirmed_orders.json` · `cutting_plans.json` · `wo_board_order.json` · `확정발주_지금.json` | **진짜 업무 자료.** 저장소에 넣지 않습니다(뿌리 `.gitignore`). 파이어스토어에서 읽기만 해서 떨구면 됩니다. |
| ② | `tests/본보기자료/` 의 같은 이름 | **본보기.** 진짜가 없으면 이것을 먹습니다. 저장소에 들어 있으므로 **받자마자 47개가 다 돕니다.** |

### 본보기자료에 무엇이 들어 있나

`도구/본보기만들기.mjs` 가 진짜 자료에서 **알아볼 수 있는 것을 다 걷어내고** 뜬 본입니다.

* **걷어낸 것** — 거래처 이름 · 상품 이름 · 상품 코드 · 대중소분류(제품군 이름) · 창고 이름
  · 발주번호. 모두 `가나가구` · `(본)본보기 상품 07` · `본보기-202601-01` 같은 본보기 말로
  바뀌었습니다. 원장에서 **앱이 안 읽는 칸 38개는 값을 통째로 비웠습니다** — 원가 ·
  원장가격 · 엣지가공비 · 보링비 · 각 공정 부속코드/부속명(상품 이름이 박혀 있던 칸)이
  여기 듭니다.
* **남긴 것** — 원장명(PB-18T…) · 마감(LPM-양면…) · 마감색상 · 부속명(가와·상판…) ·
  재단W/D · 세트별소모량 · 공급처(AMT·외부발주·공통부속) 같은 **자재 말과 숫자**.
  이것이 화면의 모든 숫자를 만들므로 없으면 시험이 아무것도 못 잽니다.
  **줄 차례도 그대로 둡니다** — 재단계획이 원장 몇째 줄인지(`pRowIndex`)로 가리키기 때문입니다.
* 만든 뒤 **바꾼 말 하나하나를 결과에서 다시 찾아봅니다.** 하나라도 남아 있으면
  만들기가 실패로 끝납니다(`샌 것 N개`).

진짜 자료가 있는 자리에서 본보기를 다시 뜨려면:

    node 에이엠티/tests/도구/본보기만들기.mjs

## 시험이 지키는 것

* **업무 자료는 읽기만 합니다.** 파이어스토어 쓰기(`setDoc`/`updateDoc`/`deleteDoc`/`addDoc`)는
  가짜로 막고 몇 번 불렸는지 셉니다 — 늘 0 이어야 합니다.
* 시험이 스스로 지어내는 발주·상품 이름도 **본보기 이름**입니다
  (`가나가구` · `샘플-20260101-01` · `(본)본보기 수납장 1200` …).
* 화면은 **폰 375px** 이 기준이고, 누르는 것은 마우스가 아니라 **진짜 손가락**
  (CDP 터치 · `tap()`)입니다. `.click()` 은 확인으로 치지 않습니다.

## 그림

    SHOTS=1 node boxes1.mjs

로 돌리면 `에이엠티/shots/` 에 그림을 다시 찍습니다. 그냥 돌리면 `tests/.그림/` 에만
남아 저장소가 더러워지지 않습니다.
