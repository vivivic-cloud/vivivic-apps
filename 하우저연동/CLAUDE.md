# 하우저연동 — 이 집에서 지킬 것

하우저(`https://www.howser.co.kr`, 가구물류 화주용) 위에 덧씌우는 **크롬 확장 「하우저 보기」**. 벤더피아연동과 같은 방식·구조다(웹 앱 아님, 크롬 컴퓨터에서만). 설치 안내 = `index.html` (https://vivivic-cloud.github.io/vivivic-apps/하우저연동/). **바이글 박스로 연결됨**(box:howser).
⚠ 고치기 전에 벤더피아연동 `CLAUDE.md` 의 표 꼴·디자인 규칙을 본다(같은 꼴을 쓴다). 옵시디언 `가구물류/하우저/` 에 화면 분석 노트가 있다.

## 지킬 것
- **로그인은 하우저 진짜 로그인 그대로, 사장님이 직접.** 아이디·비밀번호·「로그인 상태 유지」 칸은 읽지도 저장하지도 기록하지도 건드리지도 않는다(`login.js` 는 둘레만 감춘다). 서버·확장이 대신 로그인하지 않는다.
- **읽기만.** 하우저 자료 수정·삭제·신청·입점신청 금지. 쓰는 것은 화면에 그려진 표를 읽는 것 + 목록의 **쪽 번호 누르기**(조회)뿐. 아무것도 저장·전송하지 않는다.
- ⚠ 공개 저장소다. 하우저에서 읽은 재고·상품·고객 자료를 커밋하지 마라.
- 0건이어서 못 본 화면(의뢰·입고·택배·정산·구성원)은 **칸을 짓지 않는다**. 실제 데이터를 본 뒤에만.
- 새 표는 벤더피아연동·서류관리 제품관리 표 꼴(머리 13px·800·밑줄 2px / 몸 14px / 줄 #D6D6D3 / 이름 첫 칸 파란 글자 `#337ea9`)을 그대로.
- 가로 스크롤은 표 안에서만, 막대가 늘 보이게(`overflow:scroll`). 페이지 전체 가로 스크롤 금지.

## 구조 (0.2.0, 11-15)
| 하우저 주소 | 보내는 글 | 하는 일 |
|---|---|---|
| `/login` | `login.js`·`login.css` | 아이디·비밀번호 칸(`#loginId`·`#loginPw`)과 로그인 단추만 남기고 둘레(머리·꼬리)를 감춘다. 값은 안 읽는다 |
| `/home`·`/` (로그인 뒤) | `menu.js`·`menu.css` | 메뉴 단추 「재고현황」·「상품 조회」(새 탭) + 「하우저 원본」(덮은 화면을 걷음). 로그인 판별 = `#logout_button` 있음 |
| `/storage/inventory/list` | `표.js`·`표.css`·`inventory.js` | **재고현황**: 상품명이 첫 칸인 표 + 검색창(상품명·번호·상품코드·박스표기명·바코드) + 재고 기준일 표시 + 합계(정상·불량·가용·입고예정) + 줄 누름=상세 창 |
| `/product/home` | `표.js`·`표.css`·`product.js` | **상품 조회**: 상품명 첫 칸 + 등록일 기간 + 검색창 + 상세 창(「하우저에서 열기」 링크) |
| (설치 안내) | `깔렸다표시.js`·`index.html`·`howser-viewer.zip` | 확장이 깔린 곳에서 `<html data-하우저연동>` 표시만 남긴다 |

- **화면 글은 깃에서 받는다**: `불러오기.js`(확장 안, 주소를 보고 어느 글을 보낼지 정함) → `bg.js`(받아서 `chrome.scripting` 으로 넣음; 허락한 주소 = 깃 페이지 `하우저연동/` 아래 `.js`·`.css` 뿐, 쿠키 안 실음) . 못 받으면 확장 안 같은 이름 파일로 돈다(`data-hw-어디`=확장). 둘 다 안 되면 붉은 줄. → 화면 글을 고치면 **덮어쓰기 없이 새로고침만**. `manifest.json`/`bg.js`/`불러오기.js` 를 고치면 zip 을 다시 만들어 덮어쓰고 ↻ 해야 한다.
- 표 공통 `표.js`: 표를 읽고(`쪽읽기`), 하우저의 쪽 번호가 여럿이면 차례로 눌러 전부 읽고(`모든쪽읽기`) 처음 쪽으로 돌아온다. 화면별 파일은 칸 이름·순서·검색칸만 넘긴다. 칸 이름이 하우저 화면에서 바뀌면 `칸순서` 에서 빠지니(조용히) 바뀐 날은 칸 이름부터 본다.
- 판 올리기: `manifest.json` version + 표시. zip 은 `하우저보기/` 폴더로 `manifest.json bg.js 불러오기.js 깔렸다표시.js login.* menu.* 표.* inventory.js product.js` 를 담는다(CLAUDE.md·index·zip 제외).

## 알아낸 것 (2026-11-15, 사장님 로그인 크롬, 읽기만)
- 로그인: `/login` 폼 `#loginId`(휴대전화 번호)·`#loginPw`·`#inpSteady`(로그인 유지), 단추 `button.btn_comm`. `/` 는 로그인 전에도 「전체 의뢰」 껍데기를 내려준다(진짜 로그인 판단은 `#logout_button`).
- 메뉴: 포워딩(`/group/forwarding`) · 보관(`/storage/inbound/list`·`/regist`·`/storage/inventory/list`) · 시공/설치(`/home`, `/order/*`) · 상품(`/product/home`) · 정산(`/payment/download`) · 조직관리(`/member/home`) · 택배(`/parcel/list`).
- **재고현황**: 표 `#tbl_ret`, 92줄(한 쪽 100). 머리 14칸(순서: 하우저 상품번호·상품명·시공유형·박스표기명·바코드·가구사 상품코드·정상·불량·검품 대기·가용·입고 예정·출고예정(확정)·위치·메모). 머리 글에 「내림차순으로 보기」 접근성 글이 붙어 있어 지워 읽는다. 출고예정은 `0(0)` 꼴.
- **상품 조회**: 표 `table.tbl_global`, 113건 = 한 쪽 100 + 둘째 쪽 13(`.paging_global` 의 쪽 번호 `a`, 선택된 쪽 class 에 `select`). 칸: 하우저 상품번호·시공유형·상품등록 상태·상품명·가구사 상품코드·브랜드·등록일(`YYYY.MM.DD`). 상품명 칸 글에 분류(`… > 의자`)가 붙기도 한다. 상세 주소 `/product/home/<번호>` 는 표에 링크로 안 보였다(표 줄 안 `a` 없음) — 상세 창은 읽은 칸만 보이고 「하우저에서 열기」 는 링크가 있을 때만 뜬다.
- 목록은 `#key=값` 해시로 조건이 오지만 **해시를 바꿔도 다시 조회하지 않는다**(11-15 시험). 기간·조건을 우리가 바꾸지 않고, 우리 기간 칸은 이미 읽은 줄을 거르는 것뿐이다.
- 의뢰·입고·택배·정산·구성원은 0건이어서 칸을 모른다.
- 확인 못 한 것: 로그인 화면의 실제 겉모습(이미 로그인된 크롬이라 로그아웃 안 함, 받은 HTML 구조로만 짬), 확장으로 설치해서 돌려 본 것(확장 설치는 사장님이 직접).

## 변동내역
- 0.2.0 (11-15): **바이글 박스로 연결됨** — 바이글(`vivivic-cloud/viggle`) 작업대에 「하우저」 프로그램 박스(`howser`; 프로그램열기·바로가기·코드·개발자료)를 세웠다(벤더피아연동 `vl-*` 꼴). 박스는 파이어스토어 `wt_boxes` 에 있다. 확장은 크롬 컴퓨터 전용이라 박스의 「프로그램열기」는 설치 안내(`index.html`)를 연다. 이 폴더에 짚기 손잡이(`viggle.js`)는 넣지 않았다(설치 안내 화면뿐).
