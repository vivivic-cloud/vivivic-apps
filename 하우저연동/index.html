하우저 연동

하우저(howser.co.kr)를 필요한 것만 깔끔한 표로 보여 주는 크롬 확장 프로그램입니다. 하우저 아이디·비밀번호로 직접 로그인하면 재고현황·상품 조회가 보입니다. 읽기만 하고 아무것도 고치거나 저장하지 않습니다. 크롬이 깔린 컴퓨터에서만 쓸 수 있고, 폰에서는 안 됩니다.

이 컴퓨터에 깔려 있습니다

아래 단추로 하우저에 들어가 로그인하세요.

설치 방법

다른 컴퓨터에서 처음 쓸 때만 아래처럼 설치합니다. 크롬만 있으면 됩니다.

  1. 아래 버튼을 눌러 압축파일을 받습니다.
    압축파일 받기
  2. 받은 파일을 더블클릭해서 압축을 풉니다(「하우저보기」 폴더가 생깁니다).
  3. 크롬에서 chrome://extensions 를 엽니다.
  4. 오른쪽 위 「개발자 모드」를 켭니다.
  5. 「압축해제된 확장 프로그램 로드」를 누르고, 압축을 푼 「하우저보기」 폴더를 고릅니다.
  6. 하우저에 로그인하면(비밀번호는 직접 입력, 확장은 저장하지 않습니다) 메뉴에서 「재고현황」·「상품 조회」를 고릅니다. 하우저 원래 화면은 「하우저 원본」 단추로 볼 수 있습니다.

새 버전이 나오면 압축파일을 다시 받아 같은 폴더에 덮어쓰고 chrome://extensions 에서 「하우저 보기」 의 새로고침(↻)을 누릅니다. 화면 글만 고친 날은 하우저 화면을 새로고침만 해도 새것이 돕니다(화면 글은 깃허브에서 받습니다).
